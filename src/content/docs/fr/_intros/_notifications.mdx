Les notifications vous informent de vos sessions de charge, p. ex. via Telegram, Pushover, ntfy ou e-mail.
Vous choisissez quels événements déclenchent un message et pouvez personnaliser le titre et le contenu avec des espaces réservés.
La configuration se fait via **Configuration → Notifications**.
