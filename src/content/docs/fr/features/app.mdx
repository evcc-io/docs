L’interface web est le moyen le plus simple d’utiliser evcc depuis n’importe quel appareil.
Certaines fonctions ne sont toutefois possibles qu’avec une application native.

## À propos de l’application

Il existe une application compagnon officielle pour iOS et Android.
Elle trouve automatiquement les instances evcc de votre réseau et détecte mieux si elles sont en ligne ou hors ligne.
L’application adapte encore mieux l’interface web à chaque appareil.
Les interactions tactiles sont plus fiables et l’espace à l’écran est utilisé plus efficacement.
Pour en savoir plus, consultez [cette page](https://github.com/evcc-io/app?tab=readme-ov-file#features).

## Accès à distance

En tant que [parrain](/fr/sponsorship), vous pouvez utiliser l’[accès à distance](/fr/features/remote-access) pour vous connecter en déplacement.
Votre instance obtient son propre domaine sur `evcc.cloud`, et l’application s’y connecte depuis n’importe où.
Pour la configuration, il suffit de scanner un code QR.

Un VPN constitue une autre solution.
De nombreux routeurs intègrent cette fonction, mais des services comme [Tailscale](https://tailscale.com/) ou [ZeroTier](https://zerotier.com/) sont également couramment utilisés.

## Schéma d’URL

L’application enregistre un schéma d’URL `evcc://`.
Il permet de préremplir la configuration du serveur ou d’ouvrir directement une page via un lien ou un code QR.
Les liens disponibles sont décrits sur la page [Application evcc](/fr/reference/app).
