L’énergie autoproduite ne suffit pas toujours à couvrir vos propres besoins de charge, et vous devez alors recourir à l’électricité du réseau. Dans ce cas,
il est judicieux de lancer la charge lorsque la part d’énergie neutre en CO₂ dans le réseau public est la plus élevée.

Même si vous avez un tarif d’électricité verte qui annonce 0 gCO₂/kWh, la charge optimisée reste utile.
Ces tarifs sont certes neutres en CO₂ dans le bilan national, mais vous consommez le mix électrique local.
Lorsque le réseau contient peu d’énergie renouvelable, la demande d’électricité supplémentaire doit être couverte par des combustibles fossiles.

## Configurer la source de données

Pour charger de façon optimisée en CO₂, evcc a besoin de prévisions sur les émissions de CO₂ dans votre région.
Vous pouvez ajouter la source de données sous **Configuration → Tarifs & prévisions → Ajouter une prévision → Ajouter les prévisions de CO₂**.
Sélectionnez votre source de données dans le champ **Fournisseur**, p. ex. [Grünstromindex](https://www.gruenstromindex.de/) (Allemagne uniquement), et remplissez les champs propres au fournisseur, comme votre code postal.
Vous trouverez la liste de toutes les sources de données prises en charge sur la page [Tarifs](/fr/tariffs).

## Charge propre depuis le réseau

Ouvrez la boîte de dialogue des paramètres du point de charge.

<Screenshot
  name="features/screenshots/co2-loadpoint-settings"
  caption="Paramètres du point de charge"
/>

Les prévisions de CO₂ s’affichent dans le diagramme à barres.
Chaque barre représente un créneau de 15 minutes.
Vous pouvez choisir la limite CO₂ souhaitée dans le champ de sélection ou en cliquant sur une barre.

<Screenshot
  name="features/screenshots/co2-modal"
  caption="Capture d’écran de la boîte de dialogue Charge réseau intelligente avec une limite CO₂ définie"
/>

Cette limite s’applique au point de charge actuel, en mode **Intelligent**.
Si vous cliquez sur « Appliquer partout », la limite s’applique à tous les points de charge.
En plus de la charge avec le surplus solaire, le véhicule charge alors à pleine puissance pendant les heures à faibles émissions de CO₂ (barres vertes).
Ce réglage permet de garantir une batterie entièrement chargée pendant les mois d’hiver tout en soulageant le réseau.

## Plan de charge

Avec les [plans de charge](/fr/features/plans), vous pouvez piloter la charge optimisée en CO₂ encore plus précisément.
Il vous suffit de saisir la quantité d’énergie (kWh) ou le niveau de charge cible (%) et l’heure de départ souhaitée.
Lorsqu’une source de données CO₂ est configurée, l’algorithme de planification choisit automatiquement les heures où les émissions de CO₂ sont les plus faibles.

:::note[Conseil]
Si vous avez configuré un [tarif d’électricité dynamique](/fr/features/dynamic-prices), il est prioritaire.
Les données de CO₂ continuent d’être collectées pour vos sessions de charge.
L’algorithme de planification et la fonction « Chargement bon marché depuis le réseau » optimisent toutefois dans ce cas selon le prix et non plus selon le CO₂.
:::
