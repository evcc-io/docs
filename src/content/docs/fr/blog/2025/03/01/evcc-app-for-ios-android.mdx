C’est fait !
La première version de l’application evcc pour iOS et Android est prête.
Elle peut maintenant être téléchargée depuis l’[Apple App Store](https://apps.apple.com/de/app/evcc-io/id6478510176) et le [Google Play Store](https://play.google.com/store/apps/details?id=io.evcc.android).

{/* excerpt */}

## Que fait l’application ?

L’application evcc est une application native qui intègre l’interface d’evcc et vous offre une expérience optimisée sur smartphone ou tablette.
Elle apporte plusieurs fonctions pratiques qui rendent l’utilisation de votre instance evcc bien plus agréable :

### Prise en main simple

- **Détection automatique** : l’application trouve automatiquement les instances evcc de votre réseau local via mDNS.
- **Configuration manuelle** : vous pouvez aussi ajouter votre instance evcc manuellement via son URL.
- **Mode démo** : curieux ? Essayez simplement l’application avec notre instance de démonstration.

### Interface utilisateur optimisée

- **Affichage plein écran** : utilisez l’interface d’evcc en plein écran, sans les éléments du navigateur qui détournent l’attention.
- **Design adapté** : l’interface utilisateur tient compte des particularités de votre appareil (encoche, coins arrondis, etc.).
- **Gestes améliorés** : balayez et naviguez intuitivement dans l’application sans que le zoom du navigateur ou les effets de défilement élastique ne gênent.

### Connexion fiable

- **Détection en ligne/hors ligne** : l’application affiche un écran de chargement lorsque votre instance evcc n’est pas joignable.
- **Reconnexion automatique** : dès que votre instance est de nouveau disponible, l’application se reconnecte automatiquement.
- **Pas d’affichage trompeur** : l’application évite les situations trompeuses où l’interface s’affiche sans fonctionner, p. ex. à cause de problèmes réseau.

### Flexibilité

- **Changer de serveur** : vous pouvez modifier l’URL configurée à tout moment, soit en mode hors ligne, soit via l’entrée de menu « Changer de serveur ».
- **Thème clair et sombre** : l’interface native s’adapte automatiquement aux paramètres système de votre appareil.

L’application est une étape de plus pour rendre evcc encore plus simple et intuitif à utiliser.
Vous pouvez désormais garder encore mieux un œil sur votre chargeur, votre installation photovoltaïque et le flux d’énergie de votre maison, directement depuis votre smartphone.

P.-S. : vous avez un Mac avec Apple Silicon ? Vous pouvez alors y utiliser directement l’application iOS.

## La technique derrière l’application

Nous avons misé sur des technologies éprouvées pour développer l’application.
Au fond, l’application est une application native qui intègre notre vue web existante.
Nous avons choisi React Native combiné à Expo, ce qui nous permet de développer l’application pour iOS et Android avec une base de code commune.
Cela réduit nettement l’effort de développement et garantit que les nouvelles fonctionnalités arrivent rapidement sur les deux plateformes.

Les composants natifs sont écrits en TypeScript et réduits au minimum.
Pour le système de design, nous utilisons UI Kitten / Eva, qui nous aide à créer une interface utilisateur cohérente et agréable.

Comme tous nos projets, l’application est open source.
Le code source est disponible sur [GitHub](https://github.com/evcc-io/app).
Les rapports de bugs, suggestions d’amélioration et pull requests sont les bienvenus !

## Et ensuite ?

La première version de l’application est une étape importante, mais nous avons encore quelques idées passionnantes pour l’avenir :

### Simplifier l’accès à distance

Actuellement, l’application ne fonctionne que sur le même réseau que votre instance evcc.
Pour un accès à distance, vous devez établir vous-même une connexion sécurisée.
C’est déjà possible aujourd’hui avec des solutions VPN comme Wireguard (combiné à une FritzBox) ou Tailscale (avec connexions à la demande et Magic DNS), mais cela demande une configuration supplémentaire.
Nous n’avons pas encore de plans concrets pour une intégration directe dans l’application, mais c’est clairement un sujet que nous voulons traiter à moyen terme.

### Fonctionnalités propres à chaque plateforme

L’application native constitue la base de fonctionnalités supplémentaires propres à chaque plateforme, qui ne seraient pas possibles avec une simple application web.
Parmi elles, des notifications push pour vous informer des événements importants, et des widgets pour l’écran d’accueil qui vous donnent un aperçu rapide de l’état actuel de votre chargeur et de votre installation photovoltaïque.
