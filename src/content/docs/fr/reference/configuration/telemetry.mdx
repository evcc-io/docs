L’option `telemetry` active la transmission régulière de données de charge (puissance, énergie, part solaire) à evcc.io. Aucune donnée personnelle ni aucun détail de configuration n’est transmis. Pour en savoir plus, consultez la [politique de confidentialité](https://sponsor.evcc.io/privacy).

Les données agrégées sont affichées sur des plateformes comme [evcc.io](https://evcc.io). Vous pouvez accéder aux données brutes via [https://api.evcc.io/v1/total](https://api.evcc.io/v1/total).

**Par exemple** :

```yaml
telemetry: true # default: false
```
