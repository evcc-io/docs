`sponsortoken` définit le jeton de parrain obtenu sur [https://sponsor.evcc.io](https://sponsor.evcc.io).

:::tip
Nous recommandons de saisir le jeton de parrain dans l’interface web sous **Configuration**.
:::

**Par exemple** :

```yaml
sponsortoken: eyJhbGci[...]RX5s # your token from sponsor.evcc.io
```
