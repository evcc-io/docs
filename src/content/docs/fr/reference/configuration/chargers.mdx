Pour commander le processus de charge, evcc doit pouvoir communiquer avec un chargeur.

Un chargeur doit avoir au minimum la configuration suivante :

```yaml
chargers:
  - name: charger1 # reference name
    type: ...
    ...
```

Les paramètres possibles sont expliqués ci-dessous.

---

## Paramètres obligatoires

### `name`

Une désignation courte du chargeur défini ici. Cette valeur sert à référencer le chargeur dans la configuration du [point de charge](/fr/reference/configuration/loadpoints#charger).

**Par exemple** :

```yaml
name: charger1
```

---

### `type`

Il s’agit du type de chargeur propre à evcc qui permet de communiquer avec le chargeur. Les chargeurs connus peuvent être intégrés avec le type `template`. Vous trouverez le type ou le modèle adapté sous [Appareils - Chargeurs](/fr/chargers).

Pour les chargeurs inconnus (ou pour d’autres raisons particulières), définissez un [chargeur personnalisé](/fr/user-defined-devices#charger).

**Par exemple** :

```yaml
type: custom
```

---

## Paramètres facultatifs

### `integrateddevice`

Avec ce paramètre, les chargeurs qui fonctionnent sans « véhicule » (p. ex. pompe à chaleur, vélo électrique) n’affichent pas de véhicule, et la détection du véhicule est donc désactivée.

Avec ce paramètre, vous pouvez aussi attribuer une icône (voir [`vehicle.icon`](/fr/reference/configuration/vehicles#icon)), qui s’affiche alors sur le point de charge.

**Par exemple** :

```yaml
features:
  - integrateddevice
icon: bike
```

---

### `heating`

Avec ce paramètre, le niveau de charge des chargeurs du groupe « prises commutables (switchsockets) » s’affiche en degrés plutôt qu’en pourcentage.

**Exemple** :

```yaml
features:
  - heating
```

---

### `continuous`

Marque un appareil qui continue de fonctionner dans son propre mode normal lorsqu’il est « arrêté ».
L’interface affiche « Opération normale » au lieu de « En attente ».
Une demande d’augmentation de puissance (p. ex. en cas de surplus solaire ou d’électricité bon marché du réseau) est libellée « Boost ».

Activez cette fonctionnalité si votre appareil continue de fonctionner dans son mode habituel sans commande active.
Le cas d’usage typique est une pompe à chaleur ; les types de pompe à chaleur préconfigurés et les modèles correspondants activent déjà cette fonctionnalité.

**Exemple** :

```yaml
features:
  - continuous
```

---

### `switchdevice`

Marque un appareil qui ne peut être que mis en marche ou arrêté et ne prend pas en charge la régulation continue du courant (p. ex. pompes à chaleur tout-ou-rien, prises commutables).
L’interface masque les réglages de courant min/max et l’option **Toujours en charge** pour ce point de charge.

Les modèles correspondants et les types préconfigurés activent déjà cette fonctionnalité.
Pour les configurations personnalisées via `type: custom` sans régulation continue du courant, activez cette fonctionnalité.

**Exemple** :

```yaml
features:
  - switchdevice
```
