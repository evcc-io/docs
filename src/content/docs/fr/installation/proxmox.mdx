Proxmox est une plateforme de virtualisation qui permet d’héberger evcc très simplement.
Si vous prévoyez de faire tourner evcc sur un serveur domestique Linux, Proxmox peut être une alternative flexible qui permet d’installer d’autres systèmes en plus d’evcc.
Une installation d’evcc sur [Proxmox](https://www.proxmox.com/en/) se comporte alors exactement comme une installation sur un serveur Linux dédié.

L’installation suivante a été testée avec Ubuntu 24.4.

## Installation manuelle

1. Si ce n’est pas déjà fait, téléchargez un modèle Ubuntu récent sur votre serveur.
2. Créez un conteneur LX basé sur Debian et configuré avec un minimum de ressources.
   (8 Go de disque et 512 Mo de RAM suffisent largement)

   Voir la capture d’écran :

   <img src={proxmoxResources.src} alt="Capture d’écran des ressources" />

3. Installez evcc en suivant le guide [Installation sous Debian et Ubuntu](/fr/installation/linux) pour les systèmes Linux basés sur Debian.
4. Mettez à jour evcc via le gestionnaire de paquets Debian.

## Avec le script d’aide

Si vous préférez utiliser un script pour l’installation, copiez dans la console Proxmox le script bash proposé sur la page
[Proxmox VE Helper-Scripts](https://community-scripts.github.io/ProxmoxVE/scripts?id=evcc).

Cette méthode crée un conteneur avec 1 Go de RAM et, comme evcc est déjà installé, vous pouvez commencer directement
avec l’assistant de configuration. Cette page propose aussi d’autres scripts utiles, p. ex. pour les sauvegardes vers des systèmes externes.
