:::caution[Expérimental]
Le serveur MCP est expérimental et peut changer à tout moment.
:::

Le [Model Context Protocol](https://fr.wikipedia.org/wiki/Model_Context_Protocol) (MCP en abrégé) permet de donner à des LLM comme Claude, Gemini et ChatGPT un accès structuré à des systèmes externes, comme evcc.

Le serveur MCP démarre automatiquement si les fonctions expérimentales sont activées.

## Utilisation avec Claude Code

Cet exemple montre comment utiliser evcc avec Claude Code en ligne de commande.
Les serveurs MCP via HTTP ne sont actuellement disponibles qu’avec la [version payante](https://www.anthropic.com/pricing).
Vous pouvez bien sûr aussi utiliser d’autres LLM comme Gemini ou ChatGPT.

1. Installez Claude Code en suivant le [guide officiel](https://docs.anthropic.com/en/docs/claude-code/overview).

2. Créez un dossier vide pour votre test et placez-vous dans ce dossier :

   ```bash
   mkdir evcc-mcp-test
   cd evcc-mcp-test
   ```

3. Ajoutez evcc comme serveur MCP à votre espace de travail :

   ```bash
   claude mcp add --transport http evcc http://localhost:7070/mcp
   ```

4. Assurez-vous que votre instance evcc tourne avec le serveur MCP en vérifiant la carte MCP sous **Configuration** dans l’interface web.

5. Lancez Claude Code et saisissez une question.

   ```bash
   claude

   ╭──────────────────────────────────────────────────────────────────────────────────────────╮
   │ > Est-ce que je pourrai recharger ma voiture à l’énergie solaire aujourd’hui ?           │
   ╰──────────────────────────────────────────────────────────────────────────────────────────╯
   ```

6. Par défaut, Claude Code vous demande de confirmer chaque requête envoyée à votre instance evcc.

Vous pouvez alors suivre le travail de Claude Code, qui devrait finir par donner une réponse pertinente à votre question.
La question ci-dessus ne fonctionne toutefois que si vous avez configuré une [prévision solaire](/fr/tariffs#solar).

## Serveur de démonstration

MCP est activé sur le serveur de démonstration [demo.evcc.io](https://demo.evcc.io).
Vous pouvez donc aussi l’utiliser directement pour vos tests :

```bash
claude mcp add --transport http evcc-demo https://demo.evcc.io/mcp
```

Comme cette instance est utilisée par de nombreuses personnes, les résultats peuvent être peu fiables.
