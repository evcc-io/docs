Loni na konci léta nás GitHub oslovil, jestli bychom se nechtěli zapojit do [Secure Open Source Fund](https://github.com/open-source/github-secure-open-source-fund).
Přihlásili jsme se, komise nás vybrala a spolu s 98 správci z 67 open source projektů jsme prošli intenzivním bezpečnostním programem.

{/* excerpt */}

## Program

Intenzivní fáze probíhala v září 2025: zhruba 20 online setkání přes Zoom ve večerních hodinách, které účastníkům z Evropy docela vyhovovaly, i když se připojovali lidé ze všech časových pásem.
Setkání, která vedli odborníci z [GitHub Security Lab](https://securitylab.github.com/), pokrývala široké spektrum témat.
Mezi setkáními jsme měli plnit konkrétní úkoly. Domácí úkoly, ale ty účinné.
Skutečnou hodnotou však bylo slyšet, jak tato témata vysvětlují lidé, kteří se jimi zabývají každý den, a diskutovat o nich ve skupině.

## Bezpečnost je trénink, ne odškrtávací políčko

V hlavě mi utkvěl koncept _Improving Our Security Posture_.
Bezpečnost není políčko, které jednou odškrtnete. Je to spíš jako kondice.
Neexistuje žádná cílová čára.
Budujete si návyky, trénujete dál a pomalu sílíte.
Program nám dal strukturovaný tréninkový plán.

Témata byla velmi různorodá.
Pracovali jsme na jednoznačném licencování a kompatibilitě licencí, přidali kontroly licencí pro naše závislosti v Go a NPM a zveřejnili SBOM.
Napsali jsme [SECURITY.md](https://github.com/evcc-io/.github/blob/main/SECURITY.md) a plán reakce na incidenty.
Seznámili jsme se s procesem CVE. S tím jsem se zatím nemusel zabývat, ale je dobré být připraven.
Probrali jsme modelování hrozeb, principy secure-by-design a otázky UX při vývoji bezpečného softwaru.
Z nástrojů jsme probrali statickou analýzu pomocí CodeQL a fuzzing.

Nečekal jsem, že [bezpečnost GitHub Actions](https://docs.github.com/en/actions/how-tos/secure-your-work) bude tak hluboké téma.
Existuje mnoho nenápadných způsobů, jak lze workflow zneužít, a nakonec jsme svoje vlastní actions důkladně zabezpečili pomocí nástrojů jako [actions-permissions](https://github.com/GitHubSecurityLab/actions-permissions).

Jedno setkání mě překvapilo: týkalo se bezpečnosti AI.
GitHub nám představil [Secure Code Game](https://github.com/skills/secure-code-game), praktickou výzvu, ve které hledáte zranitelnosti v kódu.
První úrovně pokrývají klasické problémy z OWASP, jako jsou SQL injection a XSS. Známá půda.
Nejnovější sezóna se ale věnuje tomu, jak lstí přimět software s vestavěným LLM, aby dělal, co by neměl.
Otevřelo mi oči, že právě na tuto novou frontu se lidé aktivně připravují.

## Různé projekty, různé pohledy

Výjimečným dělalo program složení zúčastněných projektů.
Byly tam aplikace jako evcc, [Thunderbird for Android](https://github.com/thunderbird/thunderbird-android), [Mattermost](https://github.com/mattermost/mattermost) a [Mastodon](https://github.com/mastodon/mastodon).
Knihovny jako [GoReleaser](https://github.com/goreleaser/goreleaser) (ten používáme pro naše vydání), [Mermaid](https://github.com/mermaid-js/mermaid) (ten používáme v naší dokumentaci) a [Node.js](https://github.com/nodejs/node).
A základní nástroje jako [curl](https://github.com/curl/curl) a [ImageMagick](https://github.com/ImageMagick/ImageMagick).

Bezpečnost znamená něco dost odlišného podle toho, co vyvíjíte.
Aplikace, která běží v domácnostech, čelí jiným hrozbám než knihovna zabudovaná v tisících projektů.
Slyšet, jak o bezpečnosti uvažuje curl ve srovnání s Mastodonem, bylo opravdu cenné.
Kromě obsahu zůstane i síť kontaktů, kterou si s ostatními správci vybudujete.

## GitHub Universe

V říjnu 2025 jsem byl pozván na konferenci GitHub Universe v San Francisku ([více zde](https://www.linkedin.com/posts/michael-geers_homeassistant-githubuniverse-opensource-activity-7391032971517992960-a9V8)).
Na Community Day jsem se účastnil panelové diskuse o Secure Open Source Fund.
Po týdnech setkání přes Zoom bylo skvělé potkat ostatní správce osobně.

Společně s [Greggem Cochranem](https://www.linkedin.com/in/greggcochran/) (GitHub), [Christianem Grobmeierem](https://www.linkedin.com/in/grobmeier/) (Log4j), [Camilou Maiou](https://www.linkedin.com/in/cmaiacd/) (ScanAPI) a [Carlosem Alexandrem Beckerem](https://www.linkedin.com/in/caarlos0/) (GoReleaser) jsem natočil díl podcastu o bezpečnosti open source.
Můžete se [podívat na YouTube](https://www.youtube.com/watch?v=XmCSHr12CO0) nebo [si poslechnout zvukovou verzi](https://the-github-podcast.simplecast.com/episodes/live-from-github-universe-inside-the-github-secure-open-source-fund-EV0GufSU).

## Zapojte se

**Pokud spravujete open source projekt:** zvažte přihlášku do programu.
Získáte široký přehled o bezpečnostních tématech a síť kontaktů na další správce je stejně cenná.

**Pokud vaše firma závisí na open source** (a téměř jistě závisí): zvažte přímé sponzorování svých kritických závislostí.
Nebo podpořte [Secure Open Source Fund](https://github.com/open-source/github-secure-open-source-fund) a pomozte tak širšímu ekosystému.
Bezpečnější open source znamená bezpečnější software pro všechny.
