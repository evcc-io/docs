Skvělá zpráva pro řidiče vozů Škoda: Škoda spouští oficiální API pro zákazníky.
Přístup funguje s tokenem, který si vytvoříte v aplikaci MyŠkoda.
Nové API už podporujeme.

{/* excerpt */}

## Vytvořeno s komunitou

Škoda reagovala na zpětnou vazbu svých zákazníků, oslovila nás a zeptala se, co open source projekty skutečně potřebují.
Bylo pro nás důležité, aby z toho nebylo řešení výhradně pro evcc.
Proto jsme okruh rozšířili a přizvali vývojáře [integrace MyŠkoda pro Home Assistant](https://github.com/skodaconnect/homeassistant-myskoda) a knihovny pro Python [skodaconnect](https://pypi.org/project/skodaconnect/) a také [Open Home Foundation](https://www.openhomefoundation.org/).

Škoda během přípravy API na základě naší zpětné vazby opakovaně upravovala detaily.
Takto přímá spolupráce s výrobcem vozidel je pro nás nová a velmi pozitivní zkušenost.

## Jak to funguje

- Přístupový token si vytvoříte přímo v aplikaci MyŠkoda (verze 8.16, očekávaná na začátku září).
- Token spolu s identifikačním číslem vozidla (VIN) vám dá přístup k novému REST API.
- Používání API je zdarma. Není potřeba vývojářský účet, firma, NDA ani platební karta.
- [Dokumentace API](https://public.api.connect.skoda-auto.cz/docs) je veřejná.

Nové API pokrývá část dat a funkcí dosavadního neoficiálního API aplikace.
K dispozici je vše, co potřebujeme pro řízení nabíjení: stav nabití, dojezd, stav nabíjení, nabíjecí výkon a limit nabití a také spuštění a zastavení nabíjení.
Navíc jsou k dispozici další data a funkce, jako ujeté kilometry, poloha zaparkovaného vozu a klimatizace.
Které z nich jsou k dispozici, závisí na vašem vozidle a na online službách, které máte předplacené.

## Dostupnost

Podpora nového API bude součástí zítřejšího nightly sestavení.
Stabilní vydání je naplánované tak, aby vyšlo současně s aktualizací aplikace MyŠkoda 8.16.
Jakmile bude aktualizace aplikace k dispozici, můžete si vytvořit token a znovu přidat své vozidlo v evcc pomocí aktualizované integrace.

Škoda plánuje v příštích týdnech omezit přístup ke starému, neoficiálnímu API aplikace.
Vyplatí se proto brzy přejít na nové API.

## Vzor pro další výrobce

Přístup k datům vozidel byl dosud [dost kostrbatý](/cs/blog/2026/07/18/highlights-remote-access-widgets-optimizer#vw).
Tesla, Volvo a Ford nabízejí oficiální API, ale vyžadují registraci přes vývojářský portál.
U BMW a Mini vede přístup přes [portál CarData](https://www.bmw.de/de-de/mybmw/mapped-vehicle/public/car-data-info/) a vyžaduje několik kroků konfigurace.
U Škody stačí token z aplikace.
Je to zatím nejjednodušší přístup, jaký jsme viděli, a doufáme, že ostatní budou následovat.

Jednáme i s dalšími výrobci, se značkou VW už zhruba rok, zatím bez konkrétního výsledku.
Doufáme, že spuštění API dá těmto jednáním nový impuls.
Výrobci, kteří mají zájem o spolupráci, nás mohou kontaktovat na [info@evcc.io](mailto:info@evcc.io).

Spuštění tohoto API ukazuje, že zpětná vazba komunity může mít skutečný dopad.
Pokud jezdíte autem jiné značky, požádejte svého výrobce o přístup ke svým datům přes API.
Snadný přístup k datům vozidel bez závislosti na komerčních službách třetích stran je zásadní pro energetickou transformaci a decentralizovaný energetický systém.
