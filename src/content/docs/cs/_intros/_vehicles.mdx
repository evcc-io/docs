Aby bylo možné omezit nabíjení na cílový stav nabití (SoC), komunikuje evcc přímo s vozidlem přes API výrobce.
Zbývající dojezd, kapacita a stav nabíjení pocházejí ze stejného spojení.
Kvalita a dostupnost těchto API se mezi výrobci výrazně liší.
