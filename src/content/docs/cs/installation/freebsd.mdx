Tento návod popisuje instalaci na FreeBSD pomocí oficiálního [balíčku ze stromu FreeBSD Ports](https://cgit.freebsd.org/ports/tree/www/evcc).

## Instalace

<Steps>

1. ### Instalace

   Otevřete terminál s právy roota a nainstalujte evcc:

   ```sh
   pkg install evcc
   ```

2. ### Spuštění

   Povolte spouštění služby při startu systému a spusťte ji:

   ```sh
   sysrc evcc_enable="YES"
   service evcc start
   ```

3. ### Nastavení

   Otevřete rozhraní evcc v prohlížeči: [http://localhost:7070](http://localhost:7070).
   Nastavte heslo administrátora a nakonfigurujte svá zařízení přímo ve webovém rozhraní.

</Steps>

## Konfigurace

:::tip[Doporučeno]
Konfigurujte evcc přímo v prohlížeči.
:::

Po prvním spuštění můžete svou instanci evcc nakonfigurovat na adrese [http://localhost:7070](http://localhost:7070).
Nastavení se automaticky ukládají do databáze.

Případně můžete použít konfigurační soubor `evcc.yaml` v `/usr/local/etc/evcc.yaml`.
Podrobnosti najdete v části [Konfigurace](/cs/installation/configuration).

## Aktualizace

Pro aktualizaci na novou verzi proveďte následující kroky:

- Zkontrolujte ve [vydáních](https://github.com/evcc-io/evcc/releases), zda nejsou pro vaši instalaci uvedeny nekompatibilní změny (BC)
- Otevřete terminál s právy roota
- Aktualizujte evcc:

  ```sh
  pkg upgrade evcc
  ```

- Restartujte službu:

  ```sh
  service evcc restart
  ```

## Další příkazy

- Zkontrolujte stav služby evcc:

  ```sh
  service evcc status
  ```

- Zobrazte logy:

  ```sh
  tail -f /var/log/evcc.log
  ```

## nginx jako reverzní proxy

Pokud už nginx provozujete, přidejte nový virtuální host s následující konfigurací:

```nginx
server {
  ...
  server_name evcc.<your-domain>
  ...
  location / {
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header Host $http_host;

    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";

    proxy_redirect off;
    proxy_read_timeout 240s;

    proxy_http_version 1.1;

    proxy_pass http://127.0.0.1:7070;
  }
}
```

Rozhraní evcc pak bude dostupné na adrese `http://evcc.<your-domain>/`.
