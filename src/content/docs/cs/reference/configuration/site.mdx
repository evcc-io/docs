Tato sekce popisuje vaši domácí instalaci a zařízení v ní a řídí dostupný výkon.

K regulaci nabíjení ze solárního přebytku je nutný měřič přímo za předávacím místem k síti, ze kterého lze číst data. Kromě toho lze zadat měřiče fotovoltaické elektrárny a domácích baterií. Výkon více zařízení se automaticky sčítá, u domácích baterií se vypočítá průměrný stav nabití.

**Příklad**:

```yaml
site:
  title: Home # display name for UI
  meters:
    grid: mygridmeter # grid meter reference
    pv:
      - mypv1 # first pv meter reference
      - mypv9 # second pv meter reference
    battery:
      - mybat5 # battery meter reference
    aux:
      - myaux1 # self-regulating consumer
    consumer:
      - myconsumer1 # regular consumer, recorded for consumption statistics
    ext:
      - myext1 # for data logging, load management, etc.
  curtailers:
    - my_curtailer # curtailment device reference
  residualPower: 100
```

---

## Povinné parametry

### `title`

Popis nabíjecího bodu se zobrazuje i v uživatelském rozhraní.

**Příklad**:

```yaml
title: Home
```

---

### `meters`

Přiřazuje nakonfigurovaným měřičům jejich roli v domácí instalaci. Tím se definice zařízení logicky propojí s jeho zamýšleným použitím. Původně univerzální měřič tak získá účel podle svého umístění v domácí instalaci.

:::note
Je nutné nakonfigurovat alespoň jeden prvek `grid` nebo alespoň jeden prvek `pv`!

Bez alespoň jedné z těchto položek nelze evcc používat!
:::

**Příklad**:

```yaml
site:
  meters:
    grid: mygridmeter # grid meter reference
    pv: mypv1 # pv meter reference
    battery: mybat2 # battery meter reference
    aux: myaux1
```

---

## Volitelné parametry

### `meters.grid`

Určuje [`meter`](/cs/reference/configuration/meters), který poskytuje měření na předávacím místě k síti.

**Možné hodnoty**: Hodnota parametru `name` v konfiguraci [`meters`](#meters).

**Příklad**:

```yaml
grid: mygridmeter # grid meter reference
```

---

### `meters.pv`

Určuje [`meter`](/cs/reference/configuration/meters), ze kterých evcc získává měření solární výroby.
Lze zadat více zařízení. Údaje o výkonu se automaticky sčítají.

**Možné hodnoty**: Jedna hodnota nebo seznam hodnot parametru name v konfiguraci [`meters`](#meters). Seznam lze použít i pro jedinou hodnotu.

**Příklad**:

```yaml
pv: myonlypv # single pv meter reference
```

nebo

```yaml
pv: # (pvs = deprecated)
  - myoldpv # first pv meter reference
  - mynewestpv # second pv meter reference
```

---

### `meters.battery`

Určuje [`meter`](/cs/reference/configuration/meters), které poskytují naměřená data z baterie (baterií).
Lze zadat více zařízení. Údaje o výkonu se automaticky sčítají a ze stavu nabití baterií se vypočítá průměr.

**Možné hodnoty**: Jedna hodnota nebo seznam hodnot parametru `name` v konfiguraci [`meters`](#meters). Seznam lze použít i pro jedinou hodnotu.

**Příklad**:

```yaml
battery: myonlybat # single battery meter reference
```

nebo

```yaml
battery: # (batteries = deprecated)
  - mysmallbat # first battery meter reference
  - myhugebat # second battery meter reference
```

### `meters.aux`

Měřiče pro externí zařízení, která mají vlastní řízení přebytku, ale evcc je přímo neřídí, např. samoregulační topná tyč. Jejich výkon se započítává do přebytku dostupného pro nabíjení vozidla, a to za předpokladu, že zařízení sníží svou spotřebu, když evcc tento výkon přidělí nabíjení. Více měřičů se sčítá.

**Možné hodnoty**: Jedna hodnota nebo seznam hodnot parametru `name` v konfiguraci [`meters`](#meters). Seznam lze použít i pro jedinou hodnotu.

**Příklad**:

```yaml
aux: myaux # single aux meter reference
```

nebo

```yaml
aux:
  - myaux1 # first aux meter reference
  - myaux2 # second aux meter reference
```

### `meters.consumer`

Měřiče pro běžné spotřebiče, jako je pračka nebo myčka nádobí, které se zaznamenávají pouze pro statistiky spotřeby. Na rozdíl od `aux` se tento výkon nezapočítává do přebytku dostupného pro nabíjení vozidla.

**Možné hodnoty**: Jedna hodnota nebo seznam hodnot parametru `name` v konfiguraci [`meters`](#meters). Seznam lze použít i pro jedinou hodnotu.

**Příklad**:

```yaml
consumer: myconsumer # single consumer meter reference
```

nebo

```yaml
consumer:
  - myconsumer1 # first consumer meter reference
  - myconsumer2 # second consumer meter reference
```

### `meters.ext`

Měřiče, které se nepoužívají k regulaci ani se nezobrazují v uživatelském rozhraní, např. podružné rozvaděče nebo alternativní měřiče sítě či soláru. Jejich data se pouze zaznamenávají a exportují, nezapočítávají se do přebytku ani do statistik spotřeby.

**Možné hodnoty**: Jedna hodnota nebo seznam hodnot parametru `name` v konfiguraci [`meters`](#meters). Seznam lze použít i pro jedinou hodnotu.

**Příklad**:

```yaml
ext: myext # single ext meter reference
```

nebo

```yaml
ext:
  - myext1 # first ext meter reference
  - myext2 # second ext meter reference
```

### `curtailers`

Zařízení omezující výkon z konfigurace [`curtailers`](/cs/reference/configuration/curtailers), která na pokyn provozovatele distribuční soustavy omezují export do sítě (§ 9 EEG).
Uplatňují se společně s omezitelnými měřiči `pv`, když integrace [`hems`](/cs/reference/configuration/hems) signalizuje limit.

**Možné hodnoty**: Seznam hodnot parametru `name` v konfiguraci [`curtailers`](/cs/reference/configuration/curtailers).

**Příklad**:

```yaml
curtailers:
  - my_curtailer # curtailment device reference
```

### `residualPower`

Nastavuje cílový pracovní bod regulace přebytku na předávacím místě k síti (měřič sítě). Výchozí hodnota je 0 W.
Kladné hodnoty posouvají cílovou hodnotu směrem k exportu do sítě, záporné hodnoty směrem k odběru ze sítě.
Tato hodnota v konečném důsledku určuje _klidový stav_ regulační smyčky, ke kterému regulace směřuje.

Zejména v kombinaci s jinými nezávislými systémy regulace přebytku, jako je domácí baterie, je nutné tuto hodnotu upravit, aby se dosáhlo definovaného chování systému s jasnými prioritami.

Pokud má v režimu **Chytrý** zůstat nebo být povolen určitý podíl odběru ze sítě, lze nastavit zápornou hodnotu odpovídající maximálnímu podílu odběru ze sítě.

#### Je k dispozici `meter` typu `grid`

- Kladná hodnota: zbývající výkon exportu do sítě
- Záporná hodnota: zbývající výkon odběru ze sítě

#### Je k dispozici pouze `meter` typu `pv`

- Kladná hodnota: typická spotřeba domácnosti, slouží k odhadu solárního přebytku.
- Záporná hodnota: zadaný výkon se přičte k solárnímu výkonu a zvýší dostupný nabíjecí výkon (pozor: odběr ze sítě).

:::note
Pokud je k dispozici domácí baterie, důrazně doporučujeme zadat zde malou hodnotu, např. mezi 100 a 300 W, aby se baterie mohla nabíjet podle nastavených priorit (viz `prioritySoc`). Jinak nezávislá regulace domácí baterie neuvidí žádný využitelný přebytek. Zároveň se tím i bez baterie zabrání krátkodobému odběru ze sítě při rychlých změnách výroby a zátěže.
:::

**Příklad „Domácí baterie“**:

```yaml
residualPower: 100
```

**Příklad „Podíl odběru ze sítě“**:

Nabíjení se má v režimu **Chytrý** spustit s alespoň 6 A (jednofázově) i při pouhých 50 % solárního přebytku (zbytek ze sítě).
Minimální nabíjecí výkon: 1 fáze × 6 A × 230 V = 1 380 W, z toho 50 %: 690 W

Viz také [alternativu pomocí enable/disable, která umožňuje nabíjet zčásti ze soláru a zčásti ze sítě](/cs/features/solar-charging).

```yaml
residualPower: -690
```
