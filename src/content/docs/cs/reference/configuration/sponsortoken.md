`sponsortoken` určuje token, který získáte na [https://sponsor.evcc.io](https://sponsor.evcc.io).

:::tip
Doporučujeme zadat sponzorský token ve webovém rozhraní v části **Konfigurace**.
:::

**Příklad**:

```yaml
sponsortoken: eyJhbGci[...]RX5s # your token from sponsor.evcc.io
```
