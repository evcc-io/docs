Volba `telemetry` zapíná pravidelný přenos dat o nabíjení (výkon, energie, solární podíl) na evcc.io. Nepřenášejí se žádné osobní údaje ani podrobnosti konfigurace. Více se dozvíte v [zásadách ochrany osobních údajů](https://sponsor.evcc.io/privacy).

Agregovaná data se zobrazují na platformách, jako je [evcc.io](https://evcc.io). K nezpracovaným datům se dostanete přes [https://api.evcc.io/v1/total](https://api.evcc.io/v1/total).

**Příklad**:

```yaml
telemetry: true # default: false
```
