MCP server je experimentální a může se kdykoli změnit.
:::

Pomocí [Model Context Protocol](https://en.wikipedia.org/wiki/Model_Context_Protocol) (zkráceně MCP) lze jazykovým modelům, jako jsou Claude, Gemini a ChatGPT, poskytnout strukturovaný přístup k externím systémům, např. k evcc.

Pokud jsou aktivované experimentální funkce, spustí se MCP server spolu s evcc.

## Použití s Claude Code

Tento příklad ukazuje, jak můžete evcc používat s Claude Code přes CLI.
MCP servery přes HTTP jsou momentálně dostupné jen v [placené verzi](https://www.anthropic.com/pricing).
Samozřejmě můžete použít i jiné jazykové modely, např. Gemini nebo ChatGPT.

1. Nainstalujte Claude Code podle [oficiálního návodu](https://docs.anthropic.com/en/docs/claude-code/overview).

2. Vytvořte pro test prázdnou složku a přejděte do ní:

   ```bash
   mkdir evcc-mcp-test
   cd evcc-mcp-test
   ```

3. Přidejte evcc jako MCP server do svého pracovního prostoru:

   ```bash
   claude mcp add --transport http evcc http://localhost:7070/mcp
   ```

4. Na kartě MCP v konfiguraci uživatelského rozhraní ověřte, že vaše instance evcc běží s MCP serverem.

5. Spusťte Claude Code a zadejte dotaz.

   ```bash
   claude

   ╭──────────────────────────────────────────────────────────────────────────────────────────╮
   │ > Will I be able to fill my car with solar energy today?                                 │
   ╰──────────────────────────────────────────────────────────────────────────────────────────╯
   ```

6. Ve výchozím nastavení se vás systém zeptá, než odešle požadavek na evcc. Tyto požadavky musíte potvrdit.

Teď můžete sledovat, jak Claude Code pracuje, a nakonec byste měli dostat smysluplnou odpověď na svou otázku.
Výše uvedený dotaz ale funguje jen tehdy, když máte nakonfigurovanou [solární předpověď](/cs/tariffs#pv-forecast).

## Demo server

Na demo serveru [demo.evcc.io](https://demo.evcc.io) je MCP zapnutý.
Můžete tedy testovat přímo na něm:

```bash
claude mcp add --transport http evcc-demo https://demo.evcc.io/mcp
```

Protože tuto instanci používá mnoho lidí, mohou být výsledky nespolehlivé.
