:::caution[Eksperimentel]
MCP-serveren er eksperimentel og kan ændre sig når som helst.
:::

Med [Model Context Protocol](https://en.wikipedia.org/wiki/Model_Context_Protocol) (forkortet MCP) er det muligt at give LLM'er som Claude, Gemini og ChatGPT struktureret adgang til eksterne systemer, f.eks. evcc.

MCP-serveren aktiveres ved opstart, hvis eksperimentelle funktioner er slået til.

## Brug med Claude Code

Dette eksempel viser, hvordan du kan bruge evcc med Claude Code via kommandolinjen.
MCP'er via HTTP er i øjeblikket kun tilgængelige i den [betalte version](https://www.anthropic.com/pricing).
Du kan naturligvis også bruge andre LLM'er som Gemini eller ChatGPT.

1. Installer Claude Code efter den [officielle vejledning](https://docs.anthropic.com/en/docs/claude-code/overview).

2. Opret en tom mappe til din test, og gå til mappen:

   ```bash
   mkdir evcc-mcp-test
   cd evcc-mcp-test
   ```

3. Tilføj evcc som MCP-server i dit arbejdsområde:

   ```bash
   claude mcp add --transport http evcc http://localhost:7070/mcp
   ```

4. Kontrollér, at din evcc-installation kører med MCP-serveren, ved at se på MCP-kortet under opsætningen i brugergrænsefladen.

5. Start Claude Code, og indtast en forespørgsel.

   ```bash
   claude

   ╭──────────────────────────────────────────────────────────────────────────────────────────╮
   │ > Will I be able to fill my car with solar energy today?                                 │
   ╰──────────────────────────────────────────────────────────────────────────────────────────╯
   ```

6. Som standard bliver du spurgt, før systemet sender en forespørgsel til evcc. Du skal bekræfte disse forespørgsler.

Nu kan du se Claude Code arbejde og bør til sidst få et ordentligt svar på dit spørgsmål.
Forespørgslen ovenfor virker dog kun, hvis du har opsat en [solprognose](/da/tariffs#pv-forecast).

## Demoserver

MCP er aktiveret på demoserveren på [demo.evcc.io](https://demo.evcc.io).
Du kan altså også teste direkte med den:

```bash
claude mcp add --transport http evcc-demo https://demo.evcc.io/mcp
```

Da denne installation bruges af mange personer, kan resultaterne være upålidelige.
