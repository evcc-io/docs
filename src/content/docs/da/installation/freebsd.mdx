Denne vejledning beskriver installationen på FreeBSD med den officielle [pakke fra FreeBSD Ports-træet](https://cgit.freebsd.org/ports/tree/www/evcc).

## Installation

<Steps>

1. ### Installer

   Åbn en terminal som root, og installer evcc:

   ```sh
   pkg install evcc
   ```

2. ### Start

   Aktiver tjenesten ved systemstart, og start den:

   ```sh
   sysrc evcc_enable="YES"
   service evcc start
   ```

3. ### Opsætning

   Åbn evcc-webgrænsefladen i din browser: [http://localhost:7070](http://localhost:7070).
   Angiv en administratoradgangskode, og konfigurer dine enheder direkte i webgrænsefladen.

</Steps>

## Konfiguration

:::tip[Anbefalet]
Konfigurer evcc direkte i din browser.
:::

Efter første start kan du konfigurere din evcc-installation på [http://localhost:7070](http://localhost:7070).
Indstillingerne gemmes automatisk i databasen.

Alternativt kan du bruge en `evcc.yaml`-konfigurationsfil i `/usr/local/etc/evcc.yaml`.
Detaljer finder du under [Konfiguration](/da/installation/configuration).

## Opgradering

Udfør følgende trin for at opgradere til en ny version:

- Tjek [udgivelserne](https://github.com/evcc-io/evcc/releases) for breaking changes (BC), der påvirker din installation
- Åbn en terminal som root
- Opgrader evcc:

  ```sh
  pkg upgrade evcc
  ```

- Genstart tjenesten:

  ```sh
  service evcc restart
  ```

## Yderligere kommandoer

- Tjek status for evcc-serveren:

  ```sh
  service evcc status
  ```

- Vis logs:

  ```sh
  tail -f /var/log/evcc.log
  ```

## nginx som reverse proxy

Hvis nginx allerede kører, så tilføj en ny virtuel host med følgende konfiguration:

```nginx
server {
  ...
  server_name evcc.<your-domain>
  ...
  location / {
    proxy_set_header X-Forwarded-For $proxy_add_x_forwarded_for;
    proxy_set_header X-Real-IP $remote_addr;
    proxy_set_header Host $http_host;

    proxy_set_header Upgrade $http_upgrade;
    proxy_set_header Connection "upgrade";

    proxy_redirect off;
    proxy_read_timeout 240s;

    proxy_http_version 1.1;

    proxy_pass http://127.0.0.1:7070;
  }
}
```

evcc-webgrænsefladen er derefter tilgængelig på `http://evcc.<your-domain>/`.
