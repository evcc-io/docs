Indstillingen `telemetry` aktiverer regelmæssig overførsel af opladningsdata (effekt, energi, solandel) til evcc.io. Der overføres ingen personoplysninger eller konfigurationsdetaljer. Mere om dette kan du læse i [privatlivspolitikken](https://sponsor.evcc.io/privacy).

De aggregerede data vises på platforme som [evcc.io](https://evcc.io). Du kan få adgang til de rå data via [https://api.evcc.io/v1/total](https://api.evcc.io/v1/total).

**Eksempel**:

```yaml
telemetry: true # default: false
```
