Il [Model Context Protocol](https://it.wikipedia.org/wiki/Model_Context_Protocol) (in breve MCP) permette di dare agli LLM come Claude, Gemini e ChatGPT un accesso strutturato a sistemi esterni come evcc.

Il server MCP viene attivato all’avvio se le funzioni sperimentali sono abilitate.

## Uso con Claude Code

Questo esempio mostra come usare evcc con Claude Code dalla riga di comando.
I server MCP via HTTP sono al momento disponibili solo con la [versione a pagamento](https://www.anthropic.com/pricing).
Naturalmente puoi usare anche altri LLM come Gemini o ChatGPT.

1. Installa Claude Code seguendo la [guida ufficiale](https://docs.anthropic.com/it/docs/claude-code/overview).

2. Crea una cartella vuota per il tuo test e spostati in questa cartella:

   ```bash
   mkdir evcc-mcp-test
   cd evcc-mcp-test
   ```

3. Aggiungi evcc come server MCP alla tua cartella di lavoro:

   ```bash
   claude mcp add --transport http evcc http://localhost:7070/mcp
   ```

4. Verifica che la tua istanza evcc sia in esecuzione con il server MCP controllando la scheda MCP nella configurazione dell’interfaccia.

5. Avvia Claude Code e fai una domanda.

   ```bash
   claude

   ╭──────────────────────────────────────────────────────────────────────────────────────────╮
   │ > Oggi riuscirò a caricare la mia auto con energia solare?                               │
   ╰──────────────────────────────────────────────────────────────────────────────────────────╯
   ```

6. Per impostazione predefinita il sistema ti chiede conferma prima di inviare una richiesta a evcc. Devi confermare queste richieste.

Ora puoi osservare Claude Code al lavoro e alla fine dovresti ricevere una risposta adeguata alla tua domanda.
La domanda qui sopra funziona però solo se hai configurato una [previsione solare](/it/tariffs#solar).

## Server demo

MCP è attivo sul server demo all’indirizzo [demo.evcc.io](https://demo.evcc.io).
Puoi quindi fare dei test anche direttamente lì:

```bash
claude mcp add --transport http evcc-demo https://demo.evcc.io/mcp
```

Poiché questa istanza è usata da molte persone, i risultati possono essere poco affidabili.
