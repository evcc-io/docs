Il server MCP è sperimentale e può cambiare in qualsiasi momento.
:::

Il [Model Context Protocol](https://en.wikipedia.org/wiki/Model_Context_Protocol) (MCP) permette di dare ai modelli linguistici (LLM) come Claude, Gemini e ChatGPT un accesso strutturato a sistemi esterni come evcc.

Il server MCP viene attivato all’avvio se le funzioni sperimentali sono abilitate.

## Uso con Claude Code

Questo esempio mostra come usare evcc con Claude Code tramite CLI.
I server MCP via HTTP sono al momento disponibili solo con la [versione a pagamento](https://www.anthropic.com/pricing).
Naturalmente puoi usare anche altri LLM come Gemini o ChatGPT.

1. Installa Claude Code seguendo la [guida ufficiale](https://docs.anthropic.com/en/docs/claude-code/overview).

2. Crea una cartella vuota per il tuo test e spostati in questa cartella:

   ```bash
   mkdir evcc-mcp-test
   cd evcc-mcp-test
   ```

3. Aggiungi evcc come server MCP al tuo workspace:

   ```bash
   claude mcp add --transport http evcc http://localhost:7070/mcp
   ```

4. Verifica che la tua istanza evcc sia in esecuzione con il server MCP controllando la scheda MCP nella configurazione dell’interfaccia.

5. Avvia Claude Code e fai una domanda.

   ```bash
   claude

   ╭──────────────────────────────────────────────────────────────────────────────────────────╮
   │ > Will I be able to fill my car with solar energy today?                                 │
   ╰──────────────────────────────────────────────────────────────────────────────────────────╯
   ```

6. Per impostazione predefinita Claude Code ti chiede conferma prima di ogni accesso a evcc. Devi confermare queste richieste.

Ora puoi osservare Claude Code al lavoro e alla fine dovresti ricevere una risposta adeguata alla tua domanda.
La domanda qui sopra funziona però solo se hai configurato una [previsione solare](/it/tariffs#pv-forecast).

## Server demo

Il server MCP è attivo anche sull’istanza demo all’indirizzo [demo.evcc.io](https://demo.evcc.io).
Puoi quindi fare dei test anche direttamente lì:

```bash
claude mcp add --transport http evcc-demo https://demo.evcc.io/mcp
```

Poiché questa istanza è usata da molte persone, i risultati possono essere poco affidabili.
