`sponsortoken` definisce un token che ricevi su [https://sponsor.evcc.io](https://sponsor.evcc.io).

:::tip
Consigliamo di inserire il token sponsor tramite l’interfaccia web sotto **Configurazione**.
:::

**Esempio**:

```yaml
sponsortoken: eyJhbGci[...]RX5s # your token from sponsor.evcc.io
```
