L’opzione `telemetry` attiva l’invio regolare dei dati di ricarica (potenza, energia, quota solare) a evcc.io. Non vengono trasmessi dati personali né dettagli di configurazione. Puoi saperne di più nell’[informativa sulla privacy](https://sponsor.evcc.io/privacy).

I dati aggregati vengono mostrati su piattaforme come [evcc.io](https://evcc.io). Puoi accedere ai dati grezzi tramite [https://api.evcc.io/v1/total](https://api.evcc.io/v1/total).

**Esempio**:

```yaml
telemetry: true # default: false
```
