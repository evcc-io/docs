L’immagine è il modo più semplice per installare evcc su un Raspberry Pi o su un computer a scheda singola simile.
È già preconfigurata: ti resta solo da configurare evcc tramite l’interfaccia web!

## Avvio rapido

<Steps>

1. ### Scarica il file

   Trovi altri dettagli su ogni scheda (Wi-Fi, memoria, prestazioni) nell’[elenco delle schede supportate](https://github.com/evcc-io/images#supported-boards).

2. ### Scrivi l’immagine sulla scheda SD

   Ora scrivi l’immagine scaricata sulla scheda SD. Per farlo consigliamo **[Armbian Imager](https://imager.armbian.com/#downloads)**. In alternativa puoi usare [Rufus](https://rufus.ie/) (Windows).
   - Inserisci la scheda SD nel computer
   - Apri Armbian Imager
   - **Use Custom Image** → seleziona il file scaricato
   - Seleziona la tua scheda SD
   - Avvia la scrittura → attendi che finisca

   :::tip[Alternativa]
   Invece di “Scarica il file e scrivi l’immagine sulla scheda SD” puoi preparare la scheda SD anche con **[Raspberry Pi Imager](https://www.raspberrypi.com/software/)**.

   L’immagine evcc è presente nel catalogo ufficiale. Seleziona **Choose OS → Other specific-purpose OS → Home assistants and home automation → evcc**.
   :::

3. ### Avvia il Raspberry Pi
   - Inserisci la scheda SD nel Raspberry Pi
   - Collega il cavo di rete (consigliato) oppure [configura il Wi-Fi](#wifi)
   - Collega l’alimentatore
   - Attendi l’avvio

4. ### evcc Web UI

   ![Impostazione della password di evcc](../../../../assets/installation/evcc-password.webp)
   - Apri il browser
   - Inserisci **[https://evcc.local/](https://evcc.local/)**
     - Bisogna accettare l’avviso sul certificato (è normale, la connessione è crittografata)
     - In alternativa tramite indirizzo IP, ad es. `https://192.168.1.123/` (trovi l’IP nel router)
   - Imposta la password di amministratore (al primo avvio)
   - Configura i dispositivi (caricabatterie, impianto fotovoltaico, batteria domestica, veicoli)
     - Nota: perché evcc funzioni, deve essere creato almeno un punto di ricarica.

   Trovi altri dettagli sulla configurazione nella [guida alla configurazione](/it/installation/configuration).

   ![Benvenuto in evcc](../../../../assets/installation/evcc-welcome.webp)

   **Fatto!** 🎉

</Steps>

La configurazione del sistema e gli aggiornamenti si gestiscono tramite [Cockpit](#cockpit).
Accedi a Cockpit almeno una volta per cambiare la password Linux predefinita.

## Configura il Wi-Fi \{#wifi\}

Se non hai un cavo di rete a disposizione, il Raspberry Pi crea un hotspot Wi-Fi per la prima configurazione.

- Cerca la rete Wi-Fi **evcc-setup** sul tuo smartphone
- Connettiti (non serve una password)
- Seleziona dall’elenco la rete Wi-Fi di casa
- Inserisci la password della rete Wi-Fi di casa
- Il Raspberry Pi chiude l’hotspot e si connette alla rete Wi-Fi di casa
- Prosegui con [evcc Web UI](#evcc-web-ui)

Puoi configurare il Wi-Fi anche in seguito tramite [Cockpit](#cockpit).

## Gestione del sistema tramite Cockpit \{#cockpit\}

Cockpit è un’interfaccia grafica per la gestione di sistemi Linux.
Qui puoi configurare il sistema, installare aggiornamenti e modificare le impostazioni di rete.

- URL: [https://evcc.local:9090/](https://evcc.local:9090/)
- Utente: `admin`
- Password: `admin` (iniziale)

Al primo accesso ti viene chiesto di cambiare la password predefinita.
Scegli una password sicura per la gestione del sistema.
Se la dimentichi, devi riscrivere la scheda SD.
Non esiste una funzione “password dimenticata”.

![Accesso a Cockpit](../../../../assets/installation/cockpit.webp)

**Funzioni importanti:**

- **System:** panoramica di CPU, memoria e disco
- **Logs:** visualizza i [log di sistema](/it/report-a-problem#system-logs)
- **Networking:** configura rete e Wi-Fi
- **Navigator:** editor per i file di configurazione
- **Terminal:** accesso alla riga di comando
- **Software Updates:** aggiorna il sistema

:::caution
**La password di Cockpit serve solo per la gestione del sistema (incl. SSH).**

Per l’interfaccia web di evcc imposti una password di amministratore separata.
:::

## Hardware consigliato

evcc funziona su diversi computer a scheda singola e richiede poche risorse.
Anche 1 GB di RAM è più che sufficiente.

**Dispositivi supportati:**

- Raspberry Pi 4 e 5: prestazioni più che sufficienti
- Raspberry Pi 3 e Zero 2 W: sufficienti se evcc è l’unica applicazione
- NanoPi Zero2, R3S e R76S: compatti, economici, disponibili con case in metallo e memoria eMMC integrata

**Memoria:**
Almeno una scheda SD o una memoria eMMC da 16 GB.
Per una durata maggiore consigliamo la memoria eMMC invece della scheda SD (ad es. con il NanoPi).
Le schede SD possono usurarsi a causa delle frequenti operazioni di scrittura.
Vedi anche le [raccomandazioni di Armbian](https://docs.armbian.com/User-Guide_Getting-Started/#what-do-i-need).

**Alimentazione:**
Usa l’alimentatore originale del produttore della scheda.

**Rete:**
La connessione via cavo è fortemente consigliata.
Il Wi-Fi è possibile, ma spesso meno stabile.

## L’immagine Linux di evcc

L’immagine Linux di evcc si basa su [Armbian](https://www.armbian.com/) e offre alcune funzioni pratiche:

### Servizi disponibili

| Servizio    | URL                                                     | Nota                                      |
| ----------- | ------------------------------------------------------- | ----------------------------------------- |
| evcc Web UI | `https://evcc.local/`                                   | certificato self-signed **(predefinito)** |
|             | `http://evcc.local:7070/`                               | non crittografato                         |
| Server OCPP | `ws://evcc.local:8887/<station-id>`                     | non crittografato **(predefinito)**       |
|             | `wss://evcc.local:8888/<station-id>`                    | certificato self-signed                   |
| Cockpit     | `https://evcc.local:9090/` (password iniziale: `admin`) | certificato self-signed                   |
| SSH         | `ssh admin@evcc.local` (password iniziale: `admin`)     |                                           |

L’immagine offre una variante crittografata per tutti i servizi.
Consigliamo di usare connessioni crittografate anche nelle reti locali.
Per OCPP alcuni caricabatterie non supportano i certificati self-signed.
In quel caso usa WS non crittografato come ripiego.

### Aggiornamenti

- Sistema operativo: gli aggiornamenti di sicurezza vengono installati automaticamente
- evcc: gli aggiornamenti si possono eseguire manualmente tramite [Cockpit](#cockpit)

### Accesso SSH

Puoi connetterti via SSH con l’utente `admin` (stesse credenziali di [Cockpit](#cockpit)).

Trovi altri dettagli tecnici nel [repository GitHub](https://github.com/evcc-io/images).
