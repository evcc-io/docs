Proxmox è una piattaforma di virtualizzazione che permette di ospitare evcc in modo molto semplice.
Se pensi di eseguire evcc su un home server Linux, Proxmox può essere un’alternativa flessibile che ti permette di installare altri sistemi oltre a evcc.
Un’installazione di evcc su [Proxmox](https://www.proxmox.com/en/) si comporta poi esattamente come un’installazione su un server Linux dedicato.

L’installazione seguente è stata testata con Ubuntu 24.4.

## Installazione manuale

1. Se non è già presente sul tuo sistema, carica un template Ubuntu aggiornato sul tuo server.
2. Crea un container LX basato su Debian e configuralo con risorse minime.
   Bastano 8 GB di disco e 512 MB di RAM.

   Vedi lo screenshot:

   <img src={proxmoxResources.src} alt="Screenshot delle risorse" />

3. Installa evcc come descritto nella guida per i sistemi Linux basati su Debian ([Installazione su Debian, Ubuntu](/it/installation/linux)).
4. Aggiorna evcc tramite il gestore di pacchetti di Debian.

## Usare lo script helper

Se preferisci usare uno script per l’installazione, copia nella console di Proxmox lo script bash che trovi su
[Proxmox VE Helper-Scripts](https://community-scripts.github.io/ProxmoxVE/scripts?id=evcc).

In questo modo viene creato un container con 1 GB di RAM e, dato che evcc è già installato, puoi iniziare subito
con la procedura guidata di configurazione. Sullo stesso sito trovi anche altri script utili, ad es. per i backup su sistemi esterni.
