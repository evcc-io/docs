Diese Anleitung beschreibt die Installation für APT-basierte Linux-Distributionen wie Debian und Ubuntu.

:::tip[Raspberry Pi]
Für den Raspberry Pi empfehlen wir die einfachere Installation mit dem [evcc-Linux-Image](/de/installation/linux-image).
:::

:::note
Für andere Linux-Distributionen schau dir die [Docker](/de/installation/docker)-Anleitung oder den Abschnitt [Manuelle Installation](#manual) an.
:::

## Erstinstallation

<Steps>

1. ### Installieren

   Öffne ein Terminal und installiere die benötigten Abhängigkeiten:

   ```sh
   sudo apt install -y debian-keyring debian-archive-keyring apt-transport-https curl
   ```

   Füge das evcc-APT-Repository hinzu:

   <Tabs groupId="release-type">
     <TabItem label="Release" default>
       Aktuelle stabile Version

       ```sh
       curl -1sLf 'https://dl.evcc.io/public/evcc/stable/setup.deb.sh' | sudo -E bash
       ```
     </TabItem>
     <TabItem label="Nightly">
       Entwicklungsversion. Täglich aktualisiert. Kann instabil sein.

       ```sh
       curl -1sLf 'https://dl.evcc.io/public/evcc/unstable/setup.deb.sh' | sudo -E bash
       ```
     </TabItem>
   </Tabs>

   Aktualisiere die Paketliste und installiere evcc:

   ```sh
   sudo apt update
   sudo apt install -y evcc
   ```

   :::note
   Während der Installation wird ein Benutzer `evcc` angelegt, deshalb darf der angemeldete Benutzer nicht den Namen `evcc` haben.
   :::

   :::note
   Wird eine serielle Schnittstelle verwendet, musst du eventuell `sudo usermod -a -G plugdev evcc` ausführen. Das fügt den Benutzer `evcc` zur Gruppe `plugdev` hinzu und erlaubt ohne Root-Rechte den Zugriff auf angeschlossene Geräte (USB, serielle Schnittstelle usw.).
   :::

2. ### Starten

   ```sh
   sudo systemctl start evcc
   ```

3. ### Einrichten

   Öffne die evcc-Weboberfläche in deinem Browser: [http://localhost:7070](http://localhost:7070).
   Vergib ein Administrator-Passwort und richte deine Geräte direkt über die Weboberfläche ein.

</Steps>

## Konfiguration

evcc kann über die Weboberfläche oder eine Konfigurationsdatei eingerichtet werden.

:::tip[Empfohlen]
Die Konfiguration über die Weboberfläche ist der einfachste Weg, evcc einzurichten.
:::

### Weboberfläche (empfohlen)

Nach dem ersten Start kannst du evcc direkt im Browser unter [http://localhost:7070](http://localhost:7070) konfigurieren.
Die Einstellungen werden automatisch in der Datenbank gespeichert.

### Konfigurationsdatei (klassisch)

Alternativ kannst du eine Konfigurationsdatei `evcc.yaml` verwenden.
Details zur Erstellung der Konfigurationsdatei findest du unter [Einrichtung](/de/installation/configuration).

:::caution
Die Konfigurationsdatei muss unter `/etc/evcc.yaml` abgelegt werden.
:::

- Erstelle die Konfigurationsdatei gemäß der [Anleitung](/de/installation/configuration) und speichere sie unter `/etc/evcc.yaml`

- Starte den evcc-Server neu:

  ```sh
  sudo systemctl restart evcc
  ```

- Rufe die evcc-Weboberfläche unter [http://localhost:7070](http://localhost:7070) auf

## Aktualisierung

Um auf die neueste Version von evcc zu aktualisieren, führe folgende Schritte aus:

- Prüfe die [Releases](https://github.com/evcc-io/evcc/releases) auf Breaking Changes (BC), die deine Installation betreffen
- Öffne ein Terminal
- Aktualisiere die Paketliste:

  ```sh
  sudo apt update
  ```

- Aktualisiere evcc:

  ```sh
  sudo apt --only-upgrade install -y evcc
  ```

:::note
Wenn das Unstable-Repository (Nightly-Versionen) hinzugefügt wurde, wird bei jedem Update die neueste verfügbare Nightly-Version installiert.

Ist das nicht mehr gewünscht, kannst du das Unstable-Repository mit `sudo rm /etc/apt/sources.list.d/evcc-unstable.list` entfernen.
:::

## Downgrade

Falls du aus irgendeinem Grund auf eine ältere Version zurückwechseln musst, geht das mit diesem Befehl:

```sh
  sudo apt install evcc=x.xxx.x # Versionsnummer
```

## Systemdienst \{#systemd\}

evcc läuft als Systemdienst im Hintergrund. Mit diesen Befehlen kannst du den Dienst steuern:

```sh
sudo systemctl status evcc # zeigt den Status
sudo systemctl start evcc # startet den Dienst, falls er noch nicht läuft
sudo systemctl stop evcc # stoppt den Dienst
sudo systemctl restart evcc # startet den Dienst neu
sudo systemctl enable evcc # startet den Dienst automatisch beim Booten
sudo systemctl disable evcc # deaktiviert den automatischen Start beim Booten
```

## Testen

So prüfst du die Installation:

- Zeige den laufenden evcc-Dienst an:

  ```sh
  sudo systemctl status evcc
  ```

- Prüfe die letzten Log-Einträge des evcc-Dienstes:

  ```sh
  sudo journalctl -u evcc --since "yesterday"
  ```

- Prüfe die Konfiguration der Zähler:

  ```sh
  sudo evcc -l debug meter
  ```

- Prüfe die Konfiguration der Wallbox:

  ```sh
  sudo evcc -l debug charger
  ```

- Prüfe die Konfiguration der Fahrzeuge:

  ```sh
  sudo evcc -l debug vehicle
  ```

Öffne einen Browser und gib die folgende URL ein: `http://127.0.0.1:7070`.

:::note
Ersetze `127.0.0.1` durch die IP-Adresse oder den Hostnamen des Computers, falls der Browser nicht auf demselben Computer geöffnet wird.
:::

## Sichern und Wiederherstellen

### Über die Weboberfläche (empfohlen)

Am einfachsten erstellst du eine Sicherung über die Weboberfläche.
Details findest du unter [Konfiguration → Sichern & Wiederherstellen](/de/installation/configuration#backup).

### Manuelle Sicherung

Um nach einer Neuinstallation den bisherigen Zustand wiederherzustellen, reicht es, die Konfigurationsdatei `evcc.yaml` (falls verwendet) und die Datenbankdatei `evcc.db` zu sichern.
Der Speicherort wird beim Programmstart im Log ausgegeben.
Üblicherweise liegt die Konfiguration unter `/etc/evcc.yaml` und die Datenbank unter `/var/lib/evcc/evcc.db`.

Beide Dateien können mit dem Linux-Befehl `cp` kopiert werden.

Beispiel (Kopieren vom üblichen Speicherort ins Home-Verzeichnis):

Konfigurationsdatei kopieren: `sudo cp /etc/evcc.yaml /home/pi/evcc.yaml.bak`

Datenbank kopieren: `sudo cp /var/lib/evcc/evcc.db /home/pi/evcc.db.bak`

## Umgebungsvariablen & CLI-Optionen \{#environment-variables\}

Bei der Installation über APT läuft evcc als systemd-Dienst.
Du kannst das Verhalten über eine Override-Datei anpassen:

```sh
sudo systemctl edit evcc
```

:::caution
Bearbeite `/lib/systemd/system/evcc.service` nicht direkt.

Diese Datei wird bei jedem Paket-Update durch `apt` überschrieben und deine Änderungen gehen verloren.
Verwende stattdessen immer eine Override-Datei über `systemctl edit evcc`.
:::

### Beispiel

```ini title="/etc/systemd/system/evcc.service.d/override.conf"
[Service]
Environment="EVCC_LOG=debug,tariff:trace"
Environment="EVCC_DATABASE_DSN=/usb/evcc/evcc.db"
Environment="EVCC_NETWORK_HOST=my-evcc.local"
Environment="EVCC_NETWORK_PORT=80"
ExecStart=
ExecStart=/usr/bin/evcc --custom-css /path/to/my.css
```

:::note
Die erste Zeile `ExecStart=` ohne Wert ist wichtig, damit der Standardbefehl überschrieben wird.
:::

:::tip
Alle Parameter aus `evcc.yaml` können als Umgebungsvariable gesetzt werden: `EVCC_` + Parametername in Großbuchstaben.


Eine vollständige Liste aller CLI-Optionen findest du in der [CLI-Dokumentation](/de/reference/cli/evcc).
:::

## Manuelle Installation \{#manual\}

Neben dem APT-Paket für Debian/Ubuntu stellen wir auch weitere Binaries für Linux bereit.

### Installation

- Lade die passende Datei für dein System herunter:
  - 64-Bit-Intel-CPU: [evcc_X.XX_linux_amd64.tar.gz](https://github.com/evcc-io/evcc/releases/latest)
  - 64-Bit-ARM-CPU: [evcc_X.XX_linux_arm64.tar.gz](https://github.com/evcc-io/evcc/releases/latest)
  - 32-Bit-ARM-CPU (z. B. Raspberry Pi mit 32-Bit-OS): [evcc_X.XX_linux_armv6.tar.gz](https://github.com/evcc-io/evcc/releases/latest)

- Entpacke die heruntergeladene Datei (z. B. per Doppelklick).
- Im entpackten Ordner befindet sich ein Programm `evcc`.
- Öffne ein Terminal und wechsle in den neuen Ordner.
- Mit folgendem Befehl kannst du prüfen, ob evcc funktioniert:
  ```
  ./evcc -v
  ```
- Du solltest die aktuelle Version von evcc sehen (z. B. `evcc version 0.xxx.y`).

### Konfiguration

Du kannst evcc über die Weboberfläche oder eine Konfigurationsdatei einrichten.
Details findest du unter [Einrichtung](/de/installation/configuration).

Starte evcc mit:

```sh
./evcc
```

Öffne dann [http://localhost:7070](http://localhost:7070) in deinem Browser und folge den Anweisungen.

### Aktualisierung/Downgrade

Führe die obigen Schritte aus und ersetze die evcc-Programmdatei durch die neue bzw. vorherige Version.
Die Konfiguration muss nicht erneut durchgeführt werden.

### Dienst einrichten

Im produktiven Einsatz solltest du evcc als Systemdienst einrichten.
So startet evcc beim Hochfahren des Computers und wird im Fehlerfall automatisch neu gestartet.

:::note
Diese Anleitung geht davon aus, dass dein Linux-System `systemd` verwendet.
:::

- Führe folgenden Befehl aus, um eine neue Datei für den Dienst anzulegen und im Editor zu öffnen:

  ```sh
  sudo nano /etc/systemd/system/evcc.service
  ```

- Kopiere den folgenden Inhalt in die Datei:

  ```
  [Unit]
  Description=evcc
  Requires=network-online.target
  After=syslog.target network.target network-online.target
  Wants=network-online.target
  StartLimitIntervalSec=10
  StartLimitBurst=10

  [Service]
  ExecStart=/usr/local/bin/evcc
  Restart=always
  RestartSec=5

  [Install]
  WantedBy=multi-user.target
  ```

  Passe den Pfad der Datei `evcc` in `ExecStart` an, falls die Datei in einem anderen Verzeichnis liegt.
  Außerdem wird davon ausgegangen, dass die Konfigurationsdatei `evcc.yaml` unter `/etc/evcc.yaml` liegt.
  Falls nicht, ergänze am Ende von `ExecStart` den Text `-c /yourpath/evcc.yaml`.
  Ersetze `yourpath` durch das entsprechende Verzeichnis.

- Teste den Dienst:

  ```sh
  sudo systemctl daemon-reload
  sudo systemctl start evcc
  sudo systemctl status evcc
  ```

  Bei Erfolg sollte die Ausgabe Folgendes enthalten: `Active: active (running)`.

- Richte den Dienst so ein, dass er beim Systemstart automatisch startet:

  ```sh
  sudo systemctl enable evcc.service
  ```

Weitere Informationen findest du oben im Abschnitt [Systemdienst](#systemd).
