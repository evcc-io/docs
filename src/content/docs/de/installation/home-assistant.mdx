:::note
Die Home-Assistant-App von evcc ist eine Community-Integration und wird von den evcc-Maintainern nicht offiziell unterstützt.

Der Grund dafür ist, dass sich im Fehlerfall wichtige Daten nicht einfach bereitstellen lassen, weil die `evcc cli` fehlt.
:::

:::caution[Datenmigration]
Bitte beachte, dass wir am 16. Februar 2025 mit Version 0.200.1 die Pfade in der App geändert haben, damit sie den [Vorgaben](https://developers.home-assistant.io/blog/2023/11/06/public-addon-config/) von Home Assistant entsprechen.

Ab sofort werden folgende Pfade in die App eingebunden:

- `/homeassistant/` → zeigt in Home Assistant auf `/homeassistant/` bzw. `/config/`.
- `/config/` → zeigt in Home Assistant auf `/addon_configs/49686a9f_evcc/`.

Falls du von einer älteren Version aktualisierst, wird deine Konfigurationsdatei automatisch in das neue Verzeichnis kopiert.
Die Datenbank kopieren wir nur, wenn sie ebenfalls in `/config/` lag. Falls du sie in `/data/` hattest, bleibt sie dort.
Den alten Dateien hängen wir `.migrated` an. Diese kannst du dann von Hand löschen.
:::

Diese Anleitung beschreibt die Installation von evcc als Home-Assistant-App.
Im Gegensatz zur [Linux-Installation](/de/installation/linux) oder [Docker-Installation](/de/installation/docker) benötigst du hier keine Kommandozeilenkenntnisse.

## Voraussetzungen

Du benötigst eine Home-Assistant-Installation mit aktiviertem App-Store.
Abhängig von deiner Installationsart kann es sein, dass diese Funktion nicht verfügbar ist.
Weitere Informationen findest du in der [Dokumentation von Home Assistant](https://www.home-assistant.io/installation/#advanced-installation-methods).

## Konfiguration

evcc kann auf zwei Arten konfiguriert werden:

### Weboberfläche (empfohlen)

Gehe in der App **evcc** zum Tab **Information** und aktiviere **In Seitenleiste anzeigen** (Weboberfläche unter http://your-ha-instance-ip-address:7070).

Gehe zum Tab **Konfiguration** und wähle dein Arbeitsverzeichnis aus, z. B.:

<img
  src={haConfigUi.src}
  alt="Konfigurationsoberfläche der Home-Assistant-App"
/>

```sh
- sqlite_file: /data/evcc.db
```

Lass den Abschnitt Netzwerk unverändert.

Starte die App.
Öffne dann die Weboberfläche über die Seitenleiste:

- Du wirst aufgefordert, ein Administrator-Passwort festzulegen.
- Anschließend kannst du deine Geräte direkt in der Weboberfläche einrichten.
- Die Einstellungen werden automatisch in der Datenbank gespeichert.

### Konfigurationsdatei (klassisch)

Alternativ kannst du eine Konfigurationsdatei `evcc.yaml` verwenden.

Gehe zum Tab **Konfiguration** und füge die Konfigurationsdatei zu deinem Arbeitsverzeichnis hinzu:

```sh
- config_file: /config/evcc.yaml
- sqlite_file: /data/evcc.db
```

Lege eine evcc-Konfigurationsdatei `evcc.yaml` im Stammverzeichnis der App-Konfiguration (`/addon_configs/49686a9f_evcc`) an.
Falls dieser Ordner nicht existiert, lege ihn von Hand an.

Um die Konfigurationsdatei anzulegen oder zu bearbeiten, hast du mehrere Möglichkeiten:

- [Visual Studio Code](https://github.com/hassio-addons/addon-vscode): Öffne oben links das Hamburger-Menü, wähle **File** → **Open Folder…** und dann `/addon_configs/49686a9f_evcc`
- [File Editor](https://github.com/home-assistant/addons/tree/master/configurator): Stelle sicher, dass die Option **Enforce Basepath** in der App-Konfiguration deaktiviert ist, starte die App neu und navigiere zu `/addon_configs/49686a9f_evcc`
- [Advanced SSH & Web Terminal](https://github.com/hassio-addons/addon-ssh): Navigiere zu `/addon_configs/49686a9f_evcc` und verwende z. B. nano

Details zum Anlegen der Konfigurationsdatei findest du unter [Einrichtung](/de/installation/configuration).

Wenn du das System im Demo-Modus sehen möchtest, starte evcc einfach mit dem Parameter `--demo`.
Weitere Informationen findest du in der [CLI-Referenz](/de/reference/cli/evcc).

## Aktualisierung

Die Aktualisierung auf die neueste Version von evcc ist in den Aktualisierungsprozess von Home Assistant integriert.

## Tipps für Fortgeschrittene

Für die folgenden Funktionen benötigst du SSH-Zugriff auf Home Assistant. Diesen bekommst du z. B. mit der oben erwähnten SSH-App.

- Installiere [Advanced SSH & Web Terminal](https://github.com/hassio-addons/addon-ssh)
- Deaktiviere den **secure mode** in der App-Konfiguration
- Starte die App neu
- Öffne die Benutzeroberfläche der App

### Wie komme ich an die evcc-Datenbank?

Zeige die Dateien in `/data` an:

```sh
docker exec addon_49686a9f_evcc ls -la /data
```

Kopiere die `evcc.db` nach `/addon_configs/49686a9f_evcc`:

```sh
docker cp addon_49686a9f_evcc:/data/evcc.db /addon_configs/49686a9f_evcc/
```

### Wie kann ich die evcc-CLI nutzen?

Öffne eine Shell im Docker-Container von evcc:

```sh
docker exec -it addon_49686a9f_evcc /bin/sh
```

Führe evcc-CLI-Befehle aus (hier als Beispiel `checkconfig`):

```sh
evcc -c /config/evcc.yaml checkconfig
```

Schließe die Shell im Docker-Container von evcc, wenn du fertig bist:

```sh
exit
```

### Wie kann ich meinen externen Adapter oder HAT in der evcc-App für Home Assistant verwenden (Home Assistant OS, Raspberry Pi)?

Wenn sich dein Home-Assistant-Gerät in der Nähe deines Zählers (PV-Anlage, Hausbatterie, Netz usw.) befindet, kannst du die Daten auch direkt per Modbus abrufen, z. B. über USB.

Dafür musst du externe Geräte für Home Assistant und damit auch für die evcc-App freigeben.
Kommentiere dazu die Zeile `uart = 1` in der Datei `config.txt` auf der Boot-Partition von Home Assistant OS ein.

```ini title=/config.txt
uart = 1
```

Nach einem Neustart sollte dein Gerät für die evcc-App verfügbar sein (wahrscheinlich als `/dev/ttyS0` oder `/dev/ttyUSB`).
