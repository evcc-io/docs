Proxmox ist eine Virtualisierungsplattform, mit der sich evcc sehr einfach hosten lässt.
Wenn du vorhast, evcc auf einem Linux-Homeserver zu betreiben, kann Proxmox eine flexible Alternative sein, mit der du neben evcc auch noch andere Systeme installieren kannst.
Eine evcc-Installation auf [Proxmox](https://www.proxmox.com/de/) verhält sich danach genauso wie eine Installation auf einem dedizierten Linux-Server.

Die folgende Installation wurde mit Ubuntu 24.4 getestet.

## Manuelle Installation

1. Lade ein aktuelles Ubuntu-Template auf deinen Server, falls es dort noch nicht vorhanden ist.
2. Erstelle einen Debian-basierten LXC-Container mit minimalen Ressourcen.
   8 GB Festplatte und 512 MB RAM sind mehr als genug.

   Siehe Screenshot:

   <img src={proxmoxResources.src} alt="Screenshot Ressourcen" />

3. Installiere evcc wie in der Anleitung für Debian-basierte Linux-Systeme beschrieben: [Installation unter Debian, Ubuntu](/de/installation/linux).
4. Aktualisiere evcc über die Debian-Paketverwaltung.

## Installation mit Helper-Skript

Falls du lieber ein Skript zur Installation verwendest, kopiere das Bash-Skript von der Seite
[Proxmox VE Helper-Scripts](https://community-scripts.github.io/ProxmoxVE/scripts?id=evcc) in die Proxmox-Konsole.

Auf diesem Weg wird ein Container mit 1 GB RAM erstellt, und da evcc bereits installiert ist, kannst du direkt
mit dem Einrichtungsassistenten starten. Auf der Helper-Scripts-Seite gibt es auch noch weitere nützliche Skripte, z. B. für Backups auf externe Systeme.
