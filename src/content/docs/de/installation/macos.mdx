Diese Anleitung beschreibt die Installation unter macOS (10.12 und höher) mit dem Paketmanager [Homebrew](https://brew.sh).

:::note
Wenn du evcc ohne Paketmanager installieren oder eine Nightly-Version testen möchtest, schau dir den Abschnitt [Manuelle Installation](#manual) an.
:::

## Installation

<Steps>

1. ### Installieren

   Öffne ein Terminalfenster und installiere [Homebrew](https://brew.sh), falls es noch nicht installiert ist.

   ```sh
   brew trust --tap evcc-io/tap
   brew tap evcc-io/tap
   brew update
   brew install --cask evcc
   ```

2. ### Starten \{#start\}

   evcc wird als Homebrew-Cask ausgeliefert, der sich nicht mit `brew services` verwalten lässt.
   Lege stattdessen einen launchd-Agenten an. Er startet evcc bei der Anmeldung und startet es neu, falls es beendet wird:

   ```sh
   mkdir -p "$(brew --prefix)/var/log"
   cat > ~/Library/LaunchAgents/io.evcc.plist <<EOF
   <?xml version="1.0" encoding="UTF-8"?>
   <!DOCTYPE plist PUBLIC "-//Apple//DTD PLIST 1.0//EN" "http://www.apple.com/DTDs/PropertyList-1.0.dtd">
   <plist version="1.0">
   <dict>
     <key>Label</key>
     <string>io.evcc</string>
     <key>ProgramArguments</key>
     <array>
       <string>$(brew --prefix)/bin/evcc</string>
     </array>
     <key>WorkingDirectory</key>
     <string>$(brew --prefix)</string>
     <key>RunAtLoad</key>
     <true/>
     <key>KeepAlive</key>
     <true/>
     <key>StandardOutPath</key>
     <string>$(brew --prefix)/var/log/evcc.log</string>
     <key>StandardErrorPath</key>
     <string>$(brew --prefix)/var/log/evcc.log</string>
   </dict>
   </plist>
   EOF
   launchctl bootstrap gui/$(id -u) ~/Library/LaunchAgents/io.evcc.plist
   ```

3. ### Einrichten

   Öffne die Weboberfläche in deinem Browser: [http://localhost:7070](http://localhost:7070).
   Lege ein Administrator-Passwort fest und richte deine Geräte direkt über die Weboberfläche ein.

</Steps>

## Konfiguration

:::tip[Empfohlen]
Richte evcc direkt im Browser ein.
:::

Nach dem ersten Start kannst du evcc unter [http://localhost:7070](http://localhost:7070) konfigurieren.
Die Einstellungen werden automatisch in der Datenbank gespeichert.

Alternativ kannst du eine Konfigurationsdatei `evcc.yaml` unter `/etc/evcc.yaml` verwenden.
Details findest du unter [Einrichtung](/de/installation/configuration).

## Aktualisierung

Um auf eine neue Version von evcc zu aktualisieren, führe folgende Schritte aus:

- Öffne ein Terminalfenster.
- Aktualisiere die Paketlisten:

  ```sh
  brew update
  ```

- Aktualisiere evcc:

  ```sh
  brew upgrade --cask evcc
  ```

- Starte evcc neu:

  ```sh
  launchctl kickstart -k gui/$(id -u)/io.evcc
  ```

:::caution[OCPP und die macOS-Firewall]
Bei jeder Aktualisierung wird eine neue Programmdatei installiert, die die macOS-Firewall als neue Anwendung behandelt.
Ist die Firewall aktiv, werden eingehende Verbindungen blockiert, bis die neue Version freigegeben wurde.
OCPP-Wallboxen können sich dann nicht mehr verbinden, während alles andere weiter funktioniert.
Auf einem Mac ohne Bildschirm bekommst du den Freigabedialog nie zu sehen.
Gib die Programmdatei nach jeder Aktualisierung über die Kommandozeile frei:

```sh
sudo /usr/libexec/ApplicationFirewall/socketfilterfw --add "$(brew --prefix)/bin/evcc"
launchctl kickstart -k gui/$(id -u)/io.evcc
```

:::

### Umstieg von der Homebrew-Formula

Bis Version 0.314.5 wurde evcc als Homebrew-Formula ausgeliefert und mit `brew services` gestartet.
Homebrew stellt eine installierte Formula nicht auf einen Cask um, daher meldet `brew upgrade` die alte Version weiterhin als aktuell.
Entferne die Formula einmalig und installiere den Cask:

```sh
brew services stop evcc
brew uninstall evcc
brew update
brew install --cask evcc
```

Lege anschließend den launchd-Agenten wie unter [Starten](#start) beschrieben an.
Deine Konfiguration und Datenbank bleiben davon unberührt.

## Weitere Befehle

- Prüfe den Status deiner evcc-Instanz:

  ```sh
  launchctl print gui/$(id -u)/io.evcc
  ```

- Stoppe evcc und entferne den launchd-Agenten:

  ```sh
  launchctl bootout gui/$(id -u) ~/Library/LaunchAgents/io.evcc.plist
  ```

- Zeige die Logs an:

  ```sh
  tail -f "$(brew --prefix)/var/log/evcc.log"
  ```

## Manuelle Installation \{#manual\}

Hier findest du die Anleitung für die manuelle Installation von evcc unter macOS.

### Installation

- Lade die passende Datei auf dein System herunter:
  - 64-Bit-ARM- oder Intel-CPU: [evcc_X.XX_macOS_all.tar.gz](https://github.com/evcc-io/evcc/releases/latest)
- Entpacke die heruntergeladene Datei (z. B. per Doppelklick auf die Datei).
- Es gibt nun einen neuen Ordner mit dem Programm `evcc`.
- Öffne ein Terminalfenster und wechsle in den Ordner mit dem Programm `evcc`.
- Starte evcc mit folgendem Befehl:
  ```sh
  ./evcc -v
  ```
- Du solltest die aktuelle Version von evcc sehen (z. B. `evcc version 0.xxx.y`).

### Konfiguration

Öffne nach dem ersten Start [http://localhost:7070](http://localhost:7070) im Browser und richte evcc über die Weboberfläche ein.

Alternativ kannst du eine Konfigurationsdatei `evcc.yaml` erstellen (siehe [Einrichtung](/de/installation/configuration)) und evcc damit starten:

```sh
./evcc -c evcc.yaml
```

### Aktualisierung und Downgrade

Führe die obigen Schritte aus und ersetze die evcc-Programmdatei durch die neue bzw. vorherige Version.
Die Konfiguration muss nicht erneut vorgenommen werden.
