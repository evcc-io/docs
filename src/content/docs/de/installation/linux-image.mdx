Mit dem evcc-Linux-Image installierst du evcc am einfachsten auf einem Raspberry Pi oder ähnlichen Kleincomputern.
Das Image ist fertig vorkonfiguriert, und du richtest alles über die Weboberfläche ein.

## Schnellstart

<Steps>

1. ### Datei herunterladen

   Lade das aktuelle evcc-Image für dein Gerät herunter:

   | Gerät                                | Download                                                                                                                                                                                                                    |
   | ------------------------------------ | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
   | **Raspberry Pi** (3, 4, 5, Zero 2 W) | **[evcc_raspberry-pi.img.zip](https://github.com/evcc-io/images/releases/latest/download/evcc_raspberry-pi.img.zip)** ([SHA](https://github.com/evcc-io/images/releases/latest/download/evcc_raspberry-pi.img.sha))         |
   | NanoPi Zero2                         | [evcc_nanopi-zero2.img.zip](https://github.com/evcc-io/images/releases/latest/download/evcc_nanopi-zero2.img.zip) ([SHA](https://github.com/evcc-io/images/releases/latest/download/evcc_nanopi-zero2.img.sha))             |
   | NanoPi R3S                           | [evcc_nanopi-r3s.img.zip](https://github.com/evcc-io/images/releases/latest/download/evcc_nanopi-r3s.img.zip) ([SHA](https://github.com/evcc-io/images/releases/latest/download/evcc_nanopi-r3s.img.sha))                   |
   | NanoPi R76S                          | [evcc_nanopi-r76s.img.zip](https://github.com/evcc-io/images/releases/latest/download/evcc_nanopi-r76s.img.zip) ([SHA](https://github.com/evcc-io/images/releases/latest/download/evcc_nanopi-r76s.img.sha))                |
   | NanoPi NEO3 Plus                     | [evcc_nanopi-neo3-plus.img.zip](https://github.com/evcc-io/images/releases/latest/download/evcc_nanopi-neo3-plus.img.zip) ([SHA](https://github.com/evcc-io/images/releases/latest/download/evcc_nanopi-neo3-plus.img.sha)) |
   | NanoPi R28S                          | [evcc_nanopi-r28s.img.zip](https://github.com/evcc-io/images/releases/latest/download/evcc_nanopi-r28s.img.zip) ([SHA](https://github.com/evcc-io/images/releases/latest/download/evcc_nanopi-r28s.img.sha))                |

   Weitere Infos zu den einzelnen Geräten (WLAN, Speicher, Leistung) findest du in der [Liste der unterstützten Geräte](https://github.com/evcc-io/images#supported-boards).

2. ### SD-Karte beschreiben

   Schreibe jetzt das heruntergeladene Image auf die SD-Karte. Wir verwenden dafür **[Armbian Imager](https://imager.armbian.com/#downloads)**. Alternativ kannst du auch [Rufus](https://rufus.ie/) (Windows) verwenden.
   - Stecke die SD-Karte in den Computer
   - Öffne Armbian Imager
   - **Use Custom Image** → wähle die heruntergeladene Datei aus
   - Wähle deine SD-Karte aus
   - Starte das Flashen und warte, bis es fertig ist

   :::tip[Alternative]
   Statt „Datei herunterladen & SD-Karte beschreiben“ kannst du die SD-Karte auch mit dem **[Raspberry Pi Imager](https://www.raspberrypi.com/software/)** vorbereiten.

   Das evcc-Image ist im offiziellen Verzeichnis gelistet. Wähle **Choose OS → Other specific-purpose OS → Home assistants and home automation → evcc**.
   :::

3. ### Raspberry Pi starten
   - Stecke die SD-Karte in den Raspberry Pi
   - Schließe ein Netzwerkkabel an (empfohlen) oder [richte das WLAN ein](#wifi)
   - Schließe das Netzteil an
   - Warte, bis er gestartet ist

4. ### evcc Web UI

   ![evcc Passwort vergeben](../../../../assets/installation/evcc-password.webp)
   - Öffne den Browser
   - Gib **[https://evcc.local/](https://evcc.local/)** ein
     - Akzeptiere die Zertifikatswarnung (normal, die Verbindung ist verschlüsselt)
     - Alternativ via IP-Adresse, z. B. `https://192.168.1.123/` (IP im Router ermitteln)
   - Vergib ein Administrator-Passwort (beim ersten Start)
   - Richte deine Geräte ein (Wallbox, PV-Anlage, Hausbatterie, Fahrzeuge)
     - Hinweis: Mindestens ein Ladepunkt muss angelegt werden, damit evcc läuft.

   Weitere Details zur Einrichtung findest du in der [Konfigurationsanleitung](/de/installation/configuration).

   ![evcc Willkommen](../../../../assets/installation/evcc-welcome.webp)

   **Fertig!** 🎉

</Steps>

Systemkonfiguration und Updates funktionieren über [Cockpit](#cockpit).
Melde dich dort einmal an, um das Standard-Linux-Passwort zu ändern.

## WLAN einrichten \{#wifi\}

Falls kein Netzwerkkabel vorhanden ist, erstellt der Raspberry Pi einen WLAN-Hotspot für die Ersteinrichtung.

- Suche am Smartphone nach dem WLAN **„evcc-setup“**
- Verbinde dich (kein Passwort nötig)
- Wähle dein Heim-WLAN aus der Liste aus
- Gib das WLAN-Passwort deines Heimnetzwerks ein
- Der Raspberry Pi beendet den Hotspot und verbindet sich mit deinem Heim-WLAN
- Weiter mit [evcc Web UI](#evcc-web-ui)

Die WLAN-Konfiguration kann auch später über [Cockpit](#cockpit) vorgenommen werden.

## Systemverwaltung via Cockpit \{#cockpit\}

Cockpit ist eine grafische Systemverwaltung für Linux.
Hier kannst du dein System konfigurieren, Updates installieren und Netzwerkeinstellungen ändern.

- URL: [https://evcc.local:9090/](https://evcc.local:9090/)
- Benutzer: `admin`
- Passwort: `admin` (initial)

Beim ersten Login wirst du aufgefordert, das Standardpasswort zu ändern.
Wähle ein sicheres Passwort für die Systemverwaltung.
Falls du es vergisst, musst du die SD-Karte neu flashen.
Es gibt keine „Passwort vergessen“-Funktion.

![Cockpit Login](../../../../assets/installation/cockpit.webp)

**Wichtige Funktionen:**

- **System:** Übersicht über CPU, Speicher und Festplatte
- **Logs:** [Systemlogs](/de/report-a-problem#system-logs) einsehen
- **Networking:** Netzwerk und WLAN konfigurieren
- **Navigator:** Datei-Editor für Konfigurationsdateien
- **Terminal:** Zugriff auf die Kommandozeile
- **Software Updates:** System aktualisieren

:::caution
**Das Cockpit-Passwort gilt nur für die Systemverwaltung (inkl. SSH).**

Für die evcc-Weboberfläche vergibst du separat ein eigenes Administrator-Passwort.
:::

## Hardware-Empfehlungen

evcc läuft auf verschiedenen Kleincomputern und braucht nur wenig Ressourcen.
Bereits 1 GB RAM reichen völlig aus.

**Unterstützte Geräte:**

- Raspberry Pi 4 und 5: reichlich Leistung
- Raspberry Pi 3 und Zero 2 W: ausreichend, wenn evcc die einzige Anwendung ist
- NanoPi Zero2, R3S und R76S: kompakt, günstig, mit Metallgehäuse und integriertem eMMC-Speicher erhältlich

**Speicher:**
Eine SD-Karte oder ein eMMC mit mindestens 16 GB.
Für längere Lebensdauer empfehlen wir eMMC statt SD-Karte (z. B. beim NanoPi).
SD-Karten können durch häufige Schreibvorgänge verschleißen.
Siehe auch [Armbian-Empfehlungen](https://docs.armbian.com/User-Guide_Getting-Started/#what-do-i-need).

**Netzteil:**
Verwende das Original-Netzteil des jeweiligen Herstellers.

**Netzwerk:**
Eine Kabelverbindung wird dringend empfohlen.
WLAN ist möglich, aber oft weniger stabil.

## Über das evcc-Linux-Image

Das evcc-Linux-Image basiert auf [Armbian](https://www.armbian.com/) und bietet einige praktische Funktionen:

### Verfügbare Dienste

| Dienst             | URL                                                      | Hinweis                                    |
| ------------------ | -------------------------------------------------------- | ------------------------------------------ |
| evcc-Weboberfläche | `https://evcc.local/`                                    | selbstsigniertes Zertifikat **(Standard)** |
|                    | `http://evcc.local:7070/`                                | unverschlüsselt                            |
| OCPP-Server        | `ws://evcc.local:8887/<station-id>`                      | unverschlüsselt **(Standard)**             |
|                    | `wss://evcc.local:8888/<station-id>`                     | selbstsigniertes Zertifikat                |
| Cockpit            | `https://evcc.local:9090/` (initiales Passwort: `admin`) | selbstsigniertes Zertifikat                |
| SSH                | `ssh admin@evcc.local` (initiales Passwort: `admin`)     |                                            |

Das Image bietet für alle Dienste auch eine verschlüsselte Variante an.
Wir empfehlen verschlüsselte Verbindungen auch im lokalen Netzwerk.
Einige Wallboxen unterstützen bei OCPP keine selbstsignierten Zertifikate.
Nutze in dem Fall unverschlüsseltes WS als Fallback.

### Updates

- Betriebssystem: Sicherheitsupdates werden automatisch installiert
- evcc: Updates können manuell über [Cockpit](#cockpit) durchgeführt werden

### Zugriff per SSH

Du kannst dich via SSH mit dem Benutzer `admin` verbinden (gleiche Zugangsdaten wie [Cockpit](#cockpit)).

Weitere technische Details findest du im [GitHub-Repository](https://github.com/evcc-io/images).
