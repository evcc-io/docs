:::caution[Experimentell]
Der MCP-Server ist experimentell und kann sich jederzeit ändern.
:::

Über das [Model Context Protocol](https://de.wikipedia.org/wiki/Model_Context_Protocol) (kurz MCP) erhalten LLMs wie Claude, Gemini und ChatGPT strukturierten Zugriff auf externe Systeme wie evcc.

Der MCP-Server wird beim Start aktiviert, wenn experimentelle Funktionen eingeschaltet sind.

## Verwendung mit Claude Code

Dieses Beispiel zeigt, wie du evcc mit Claude Code auf der Kommandozeile nutzen kannst.
MCP-Server per HTTP lassen sich aktuell nur mit der [Bezahlversion](https://www.anthropic.com/pricing) einbinden.
Natürlich kannst du auch andere LLMs wie Gemini oder ChatGPT nutzen.

1. Installiere Claude Code anhand der [offiziellen Anleitung](https://docs.anthropic.com/en/docs/claude-code/overview).

2. Erstelle einen leeren Ordner für deinen Test und wechsle in diesen Ordner:

   ```bash
   mkdir evcc-mcp-test
   cd evcc-mcp-test
   ```

3. Füge evcc als MCP-Server zu diesem Projektordner hinzu:

   ```bash
   claude mcp add --transport http evcc http://localhost:7070/mcp
   ```

4. Stelle sicher, dass deine evcc-Instanz mit dem MCP-Server läuft, indem du in der Oberfläche unter **Konfiguration** nachsiehst, ob die MCP-Kachel angezeigt wird.

5. Starte Claude Code und gib eine Anfrage ein.

   ```bash
   claude

   ╭──────────────────────────────────────────────────────────────────────────────────────────╮
   │ > Kann ich mein Auto heute noch mit PV-Strom vollladen?                                  │
   ╰──────────────────────────────────────────────────────────────────────────────────────────╯
   ```

6. Standardmäßig fragt Claude Code nach, bevor es auf deine evcc-Instanz zugreift. Diese Zugriffe musst du bestätigen.

Jetzt kannst du Claude Code dabei zusehen, wie es arbeitet, und solltest am Ende eine fundierte Antwort auf deine Frage erhalten.
Die obige Anfrage funktioniert allerdings nur, wenn du eine [PV-Vorhersage](/de/tariffs#solar) konfiguriert hast.

## Demo-Server

Auf dem Demo-Server unter [demo.evcc.io](https://demo.evcc.io) ist MCP aktiviert.
Du kannst MCP also auch direkt dort ausprobieren:

```bash
claude mcp add --transport http evcc-demo https://demo.evcc.io/mcp
```

Da diese Instanz von vielen Personen genutzt wird, können die Ergebnisse unzuverlässig sein.
