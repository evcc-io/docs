:::caution[Experimentell]
Das Lastmanagement ist noch experimentell. In Kombination mit einigen anderen Funktionen verhält es sich möglicherweise nicht wie erwartet.
:::

Mit dem Lastmanagement (Lastausgleich) lässt sich die Leistung von Wallboxen begrenzen, um eine Überlastung der Stromkreise und das Auslösen von Sicherungen zu verhindern.
Die Begrenzung der Leistung kann auch nützlich sein, wenn du ungewollte Lastspitzen vermeiden willst.
Dazu kann ein Ladepunkt einem Stromkreis (`circuit`) zugeordnet werden.
Ein Stromkreis (`circuit`) kann eine maximale Stromstärke (`maxCurrent`) und/oder eine maximale Leistung (`maxPower`) haben.
Das System arbeitet hierarchisch, d. h. ein Stromkreis kann Teil eines übergeordneten Stromkreises sein.

:::note[Konfiguration über die Oberfläche]
Diese Seite beschreibt die Konfiguration über die Datei `evcc.yaml`.
Die Konfiguration ist auch über die Oberfläche möglich.

Stromkreise können unter **Konfiguration → Lastmanagement** angelegt werden.
Die Eingabe erfolgt im YAML-Format und entspricht dem Inhalt unterhalb von `circuits:` in den folgenden Beispielen.
Wir arbeiten daran, dies durch eine formularbasierte Eingabe zu ersetzen.

Anschließend kann jeder Ladepunkt unter **Konfiguration → Ladepunkte & Heizungen → [Name]** einem Stromkreis zugeordnet werden (Neustart erforderlich).
:::

## Konfiguration

Im Abschnitt `circuits` werden die Stromkreise definiert.
Jeder Ladepunkt kann dann einem Stromkreis zugeordnet werden.

### Beispiel: Hauptstromkreis

```yaml
circuits:
  - name: main # eindeutiger Name, andere Stromkreise verweisen über parent darauf
    title: "Hauptstromkreis" # Name für die Oberfläche (dort noch nicht umgesetzt)
    maxCurrent: 63 # 63 A (optional)
    maxPower: 30000 # 30 kW (optional)
    meter: grid # optional

loadpoints:
  - title: Garage
    circuit: main
    # ...
  - title: Carport
    circuit: main
    # ...
```

Diese Konfiguration definiert den Hauptstromkreis `main` mit einer maximalen Leistung von 30 kW und einer maximalen Stromstärke von 63 A pro Phase.
Die Ladepunkte _Garage_ und _Carport_ sind diesem Stromkreis zugeordnet.
Ziehen andere Verbraucher wie ein Backofen oder eine Wärmepumpe (dafür ist ein Zähler nötig) insgesamt 50 A, dürfen die Ladepunkte nur noch die verbleibenden 13 A nutzen.
Da der Netzzähler diesem Stromkreis zugeordnet ist, wird die Leistung der Ladepunkte so gedrosselt, dass die Grenzwerte am Netzanschluss nicht überschritten werden.
Ohne Zuordnung des Netzzählers gelten die Grenzwerte direkt für die Summe aller Ladepunkte.

### Beispiel: Verschachtelte Stromkreise

```yaml
circuits:
  - name: main
    title: "Hauptstromkreis"
    maxCurrent: 48
  - name: garage
    title: Garage
    maxCurrent: 32
    parent: main
  - name: carport
    title: Carport
    maxCurrent: 32
    parent: main

loadpoints:
  - title: Garage A
    circuit: garage
  - title: Garage B
    circuit: garage
  - title: Garage C
    circuit: garage
  - title: Carport A
    circuit: carport
  - title: Carport B
    circuit: carport
  - title: Wärmepumpe
    circuit: main
```

Hier gibt es zwei Stromkreise, `garage` und `carport`, die beide dem Hauptstromkreis untergeordnet sind (`parent: main`).
Der Stromkreis `main` hat eine maximale Stromstärke von 48 A.
Die Stromkreise `garage` und `carport` haben jeweils eine maximale Stromstärke von 32 A.
Die Ladepunkte Garage A, Garage B und Garage C sind dem Stromkreis `garage` zugeordnet (`circuit: garage`).
Die Ladepunkte Carport A und Carport B sind dem Stromkreis `carport` zugeordnet (`circuit: carport`).
Die Stromkreise `garage` und `carport` sowie die Wärmepumpe sind direkt an den Hauptstromkreis (`main`) angeschlossen.
Die Regelung stellt sicher, dass die Grenzwerte der jeweiligen Stromkreise zu keinem Zeitpunkt überschritten werden.

**Wichtig:** Es muss immer genau einen Hauptstromkreis geben (einen Stromkreis ohne die Eigenschaft `parent`).

:::note[Externe Begrenzung (§ 14a, § 9)]
Wenn eine [externe Begrenzung](/de/external-limit) aktiv ist, begrenzt sie die Leistung des Hauptstromkreises.
Das zeigt der Hinweis **Verbrauch begrenzt** auf der Lastmanagement-Kachel an.
:::

## Messwerte

Standardmäßig berechnet die Regelung die aktuelle Leistung und Stromstärke aus der Summe der jeweils zugeordneten Ladepunkte.
Wird an einem Stromkreis (`circuit`) ein Zähler (`meter`) konfiguriert, kann auch die tatsächliche Last berücksichtigt werden.
Das ist besonders sinnvoll, wenn an der Sicherung noch weitere Verbraucher angeschlossen sind.

```yaml
site:
  meters:
    ext:
      - carport_meter

meters:
  - name: carport_meter
    type: template
    template: shelly-3em

circuits:
  - name: carport
    meter: carport_meter
    maxCurrent: 32
```

Hinweis: Kommt ein Zähler zum Einsatz, der noch nicht für einen anderen Zweck (z. B. `grid`) verwendet wird, muss er als externer Zähler unter `site.meters.ext` eingebunden werden.

## Grenzwerte

An jedem Stromkreis kann sowohl eine maximale Stromstärke pro Phase (`maxCurrent`) als auch eine maximale Leistung (`maxPower`) konfiguriert werden.
Diese Werte werden, sofern konfiguriert, unabhängig voneinander überwacht.

### Externe Grenzwerte

Bei Bedarf können mit `GetMaxCurrent` und `GetMaxPower` auch externe Grenzwerte definiert werden. Im Fehlerfall gelten die fest definierten Grenzwerte.

Beispiel:

```yaml
circuits:
  - name: main
    title: "Hauptstromkreis"
    maxCurrent: 48
    GetMaxCurrent:
      source: mqtt
      topic: ext/maxcurrent
    maxPower: 33000
    GetMaxPower:
      source: mqtt
      topic: ext/maxpower
```

:::note[Hinweis]
Mit einer externen Begrenzung lassen sich Steuerungsanweisungen des Netzbetreibers umsetzen.
Weitere Informationen findest du unter [Externe Begrenzung](/de/external-limit).
:::

## Phasenumschaltung

Bei Wallboxen mit automatischer Phasenumschaltung (1P/3P) kann das Lastmanagement die Umschaltung nutzen, um innerhalb der konfigurierten Grenzwerte zu laden.
Reicht die verfügbare Leistung nicht für 3-phasiges Laden, schaltet evcc automatisch auf 1-phasiges Laden um.

Das gilt auch im Modus **Schnell** und beim Laden nach Ladeplan.
Begrenzt das Lastmanagement die verfügbare Leistung z. B. auf 3,5 kW, schaltet evcc auf 1-phasiges Laden (ab 1,4 kW) um, statt den Ladevorgang zu pausieren.

**Voraussetzung:** Die Wallbox muss Phasenumschaltung unterstützen.

## Wallbox-Konfiguration

Einige Wallboxen bringen eigene Lastmanagement-Funktionen mit.
Wir empfehlen dringend, diese zu deaktivieren oder Wallboxen ohne eigene Logik zu verwenden.
evcc erwartet, dass Geräte seine Steuerbefehle direkt umsetzen.
Andere Konfigurationen können zu unerwartetem Verhalten führen und müssen von dir selbst gründlich getestet werden.

## Einschränkungen

:::note
Für die kommerzielle Nutzung des Lastmanagements wird später eine separate Lizenz erforderlich sein.
Die private Nutzung mit kleineren Installationen bleibt kostenlos.
:::

- Die aktuellen Werte und Grenzwerte der einzelnen Stromkreise werden auf der Konfigurationsseite der Oberfläche angezeigt. Eine Visualisierung am Ladepunkt ist geplant.
- Die Einstellung `priority` am Ladepunkt wird noch nicht berücksichtigt.
- Neue Ladevorgänge erhalten nur den verbleibenden Spielraum im Stromkreis.
  Eine Umverteilung zwischen laufenden Ladevorgängen wird noch nicht unterstützt.
- [Netzladen](/de/features/battery#gridcharge) der Hausbatterie wird nicht berücksichtigt. Wenn die Hausbatterie aktiv aus dem Netz lädt, fließt dieser Verbrauch nicht in die Berechnungen des Lastmanagements ein. Bei aktiven Signalen zur [Leistungsreduzierung nach § 14a](/de/external-limit) wird das Netzladen jedoch automatisch pausiert.
