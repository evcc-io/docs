Dieser Abschnitt beschreibt den Standort mit den vorhandenen und benötigten Geräten der Hausinstallation und regelt die verfügbare Leistung.

Um das Laden mit PV-Überschuss zu regeln, ist ein auslesbarer Zähler direkt hinter dem Netzanschlusspunkt notwendig. Zusätzlich können Geräte für die PV-Leistung und Hausbatterie(n) angegeben werden. Bei mehreren Geräten werden die Leistungen automatisch addiert, bei Hausbatterien wird zusätzlich der mittlere Ladestand gebildet.

**Beispiel**:

```yaml
site:
  title: Zuhause # Anzeigename in der UI
  meters:
    grid: mygridmeter # Referenz auf den Netzzähler
    pv:
      - mypv1 # Referenz auf den ersten PV-Zähler
      - mypv9 # Referenz auf den zweiten PV-Zähler
    battery:
      - mybat5 # Referenz auf den Batteriezähler
    aux:
      - myaux1 # selbstregelnder Verbraucher
    consumer:
      - myconsumer1 # regulärer Verbraucher, erfasst für die Verbrauchsstatistik
    ext:
      - myext1 # für Datenaufzeichnung, Lastmanagement usw.
  curtailers:
    - my_curtailer # Referenz auf den Einspeisebegrenzer
  residualPower: 100
```

---

## Erforderliche Parameter

### `title`

Der Name des Standorts, der in der UI als Titel angezeigt wird.

**Beispiel**:

```yaml
title: Zuhause
```

---

### `meters`

Definiert, welche konfigurierten [`meter`](/de/reference/configuration/meters) (Zähler) als welche Art von Messpunkt verwendet werden sollen. Hier erfolgt die logische Verknüpfung der Gerätedefinition mit dem Verwendungszweck. Ein zunächst universeller Zähler bekommt so entsprechend seinem Einbauort in der Hausinstallation einen Zweck zugewiesen.

:::note
Mindestens ein `grid`- oder `pv`-Eintrag ist notwendig.

Ohne einen dieser Einträge funktioniert evcc nicht.
:::

**Beispiel**:

```yaml
site:
  meters:
    grid: mygridmeter # Referenz auf den Netzzähler
    pv: mypv1 # Referenz auf den PV-Zähler
    battery: mybat2 # Referenz auf den Batteriezähler
    aux: myaux1
```

---

## Optionale Parameter

### `meters.grid`

Definiert das [`meter`](/de/reference/configuration/meters) (Zähler), das die Messwerte des Netzanschlusspunkts liefert.

**Mögliche Werte**: Wert eines `name`-Parameters in der [`meters`](#meters)-Konfiguration.

**Beispiel**:

```yaml
grid: mygridmeter # Referenz auf den Netzzähler
```

---

### `meters.pv`

Definiert die [`meter`](/de/reference/configuration/meters) (Zähler), von denen evcc die PV-Erzeugungswerte abruft.
Es können mehrere Geräte angegeben werden. Die Leistungsdaten werden automatisch addiert.

**Mögliche Werte**: Ein einzelner Wert oder eine Liste von Werten eines name-Parameters in der [`meters`](#meters)-Konfiguration. Die Listenform kann auch bei Einzelwerten genutzt werden.

**Beispiel**:

```yaml
pv: myonlypv # Referenz auf einen einzelnen PV-Zähler
```

oder

```yaml
pv: # (pvs = veraltet)
  - myoldpv # Referenz auf den ersten PV-Zähler
  - mynewestpv # Referenz auf den zweiten PV-Zähler
```

---

### `meters.battery`

Definiert die [`meter`](/de/reference/configuration/meters) (Zähler), welche die Messdaten der Hausbatterie(n) liefern.
Es können mehrere Geräte angegeben werden. Die Leistungsdaten werden automatisch addiert und aus den Ladeständen der Batterien wird ein Mittelwert gebildet.

**Mögliche Werte**: Ein einzelner Wert oder eine Liste von Werten eines `name`-Parameters in der [`meters`](#meters)-Konfiguration. Die Listenform kann auch bei Einzelwerten genutzt werden.

**Beispiel**:

```yaml
battery: myonlybat # Referenz auf einen einzelnen Batteriezähler
```

oder

```yaml
battery: # (batteries = veraltet)
  - mysmallbat # Referenz auf den ersten Batteriezähler
  - myhugebat # Referenz auf den zweiten Batteriezähler
```

### `meters.aux`

Zähler für externe Geräte, die über eine eigene Überschussregelung verfügen, aber nicht direkt durch evcc gesteuert werden, z. B. ein selbstregelnder Heizstab. evcc rechnet ihre Leistung dem verfügbaren Überschuss für das Laden des Fahrzeugs zu und geht davon aus, dass das Gerät seinen Verbrauch reduziert, sobald evcc diese Leistung dem Laden zuteilt. Mehrere Zähler werden addiert.

**Mögliche Werte**: Ein einzelner Wert oder eine Liste von Werten eines `name`-Parameters in der [`meters`](#meters)-Konfiguration. Die Listenform kann auch bei Einzelwerten genutzt werden.

**Beispiel**:

```yaml
aux: myaux # Referenz auf einen einzelnen aux-Zähler
```

oder

```yaml
aux:
  - myaux1 # Referenz auf den ersten aux-Zähler
  - myaux2 # Referenz auf den zweiten aux-Zähler
```

### `meters.consumer`

Zähler für reguläre Verbraucher wie Waschmaschine oder Spülmaschine, die ausschließlich für die Verbrauchsstatistik erfasst werden. Anders als bei `aux` fließt diese Leistung nicht in den verfügbaren Überschuss für das Laden des Fahrzeugs ein.

**Mögliche Werte**: Ein einzelner Wert oder eine Liste von Werten eines `name`-Parameters in der [`meters`](#meters)-Konfiguration. Die Listenform kann auch bei Einzelwerten genutzt werden.

**Beispiel**:

```yaml
consumer: myconsumer # Referenz auf einen einzelnen Verbraucherzähler
```

oder

```yaml
consumer:
  - myconsumer1 # Referenz auf den ersten Verbraucherzähler
  - myconsumer2 # Referenz auf den zweiten Verbraucherzähler
```

### `meters.ext`

Zähler, die weder für die Regelung verwendet noch in der UI angezeigt werden, z. B. Unterverteilungen oder alternative Netz- oder PV-Zähler. Ihre Daten werden nur aufgezeichnet und exportiert, fließen aber nicht in den Überschuss oder die Verbrauchsstatistik ein.

**Mögliche Werte**: Ein einzelner Wert oder eine Liste von Werten eines `name`-Parameters in der [`meters`](#meters)-Konfiguration. Die Listenform kann auch bei Einzelwerten genutzt werden.

**Beispiel**:

```yaml
ext: myext # Referenz auf einen einzelnen ext-Zähler
```

oder

```yaml
ext:
  - myext1 # Referenz auf den ersten ext-Zähler
  - myext2 # Referenz auf den zweiten ext-Zähler
```

### `curtailers`

Einspeisebegrenzer aus der [`curtailers`](/de/reference/configuration/curtailers)-Konfiguration, die die Einspeisung auf Anforderung des Netzbetreibers begrenzen (§ 9 EEG).
Sie werden zusammen mit den abregelbaren `pv`-Zählern angesteuert, wenn die [`hems`](/de/reference/configuration/hems)-Integration ein Limit signalisiert.

**Mögliche Werte**: Eine Liste von Werten eines `name`-Parameters in der [`curtailers`](/de/reference/configuration/curtailers)-Konfiguration.

**Beispiel**:

```yaml
curtailers:
  - my_curtailer # Referenz auf den Einspeisebegrenzer
```

### `residualPower`

Legt den Soll-Arbeitspunkt der Überschussregelung am Netzanschlusspunkt (Netzzähler) fest. Der Standardwert ist 0 W.
Positive Werte verschieben den Sollwert in Richtung Einspeisung, negative Werte in Richtung Netzbezug.
Letztlich legt dieser Wert den _Ruhezustand_ des Regelkreises fest, den die Regelung einstellen muss.

Insbesondere im Zusammenspiel mit weiteren unabhängigen Überschussregelungen, z. B. einer Hausbatterie, muss dieser Wert angepasst werden, um ein definiertes Systemverhalten mit klaren Prioritäten zu erreichen.

Soll im Smart-Modus ein Teil der Ladeleistung aus dem Netz kommen dürfen, trägst du als negativen Wert den maximal erlaubten Netzbezug ein.

#### Mit Netzzähler (`grid` `meter`)

- Positiver Wert: Verbleibende Einspeiseleistung
- Negativer Wert: Verbleibende Netzbezugsleistung

#### Nur mit PV-Zähler (`pv` `meter`)

- Positiver Wert: Typischer Hausverbrauch, um damit den PV-Überschuss abzuschätzen
- Negativer Wert: Die angegebene Leistung wird zur PV-Leistung addiert und erhöht die verfügbare Ladeleistung (Achtung: Netzbezug)

:::note
Bei vorhandener Hausbatterie wird dringend empfohlen, hier einen kleinen Wert einzutragen, z. B. zwischen 100 und 300 W, um eine Batterieladung gemäß den konfigurierten Prioritäten (siehe `prioritySoc`) zu ermöglichen. Andernfalls sieht die unabhängige Regelung der Hausbatterie keinen nutzbaren Überschuss. Ebenso lässt sich damit bei schnellen Erzeugungs- und Lastwechseln auch ohne Hausbatterie ein kurzzeitiger Netzbezug vermeiden.
:::

**Beispiel „Hausbatterie“**:

```yaml
residualPower: 100
```

**Beispiel „Netzbezugsanteil“**:

Im Smart-Modus soll das Laden mit mindestens 6 A (einphasig) schon bei nur 50% PV-Überschuss starten (der Rest kommt aus dem Netz).
Mindestladeleistung: 1 Phase × 6 A × 230 V = 1.380 W, davon 50%: 690 W

Siehe auch die [Alternative mittels enable/disable, um anteilig PV und Netzbezug zu erlauben](/de/features/solar-charging).

```yaml
residualPower: -690
```
