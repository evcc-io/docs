`sponsortoken` definiert einen Token, der auf [https://sponsor.evcc.io](https://sponsor.evcc.io) vergeben wird.

:::tip
Wir empfehlen die Eingabe des Sponsortokens über die Weboberfläche unter **Konfiguration**.
:::

**Beispiel**:

```yaml
sponsortoken: eyJhbGci[...]RX5s # dein Token von sponsor.evcc.io
```
