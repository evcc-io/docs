Zur Steuerung der Ladung muss evcc mit einer Wallbox kommunizieren können.

Eine Wallbox braucht mindestens folgende Konfiguration:

```yaml
chargers:
  - name: wallbox1 # Referenzname
    type: ...
    ...
```

Im Folgenden werden die möglichen Parameter erklärt.

---

## Erforderliche Parameter

### `name`

Eine Kurzbezeichnung der hier definierten Wallbox. Der Wert wird verwendet, um die Wallbox in der Konfiguration des [Ladepunkts](/de/reference/configuration/loadpoints#charger) zu referenzieren.

**Beispiel**:

```yaml
name: wallbox1
```

---

### `type`

Dies ist der evcc-spezifische Wallbox-Typ, über den die Kommunikation mit der Wallbox läuft. Bekannte Wallboxen können über den Typ `template` eingebunden werden. Den passenden (Template-)Typ findest du unter [Geräte – Wallboxen](/de/chargers).

Für unbekannte Wallboxen (oder aus anderen individuellen Gründen) definiere eine [benutzerdefinierte Wallbox](/de/user-defined-devices#charger).

**Beispiel**:

```yaml
type: custom
```

---

## Optionale Parameter

### `integrateddevice`

Dieser Parameter bewirkt, dass bei Wallboxen, die ohne „Fahrzeug“ betrieben werden (z. B. Wärmepumpe, E-Bike), kein Fahrzeug angezeigt wird und dadurch auch die Fahrzeugerkennung entfällt.

In Verbindung mit diesem Parameter kann auch ein Icon vergeben werden (siehe [`vehicle.icon`](/de/reference/configuration/vehicles#icon)), das dann an der Wallbox angezeigt wird.

**Beispiel**:

```yaml
features:
  - integrateddevice
icon: bike
```

---

### `heating`

Dieser Parameter bewirkt, dass bei _schaltbaren Steckdosen_ (switchsockets) statt des Ladestands in Prozent ein Wert in Grad angezeigt wird.

**Beispiel**:

```yaml
features:
  - heating
```

---

### `continuous`

Markiert ein Gerät, das im Modus **Aus** eigenständig in seinem Normalbetrieb weiterläuft.
Die Oberfläche zeigt **Normaler Betrieb** statt **Standby** an.
Eine Anforderung zur Leistungserhöhung (z. B. bei PV-Überschuss oder günstigem Netzstrom) wird als **Boost** gekennzeichnet.

Setze diesen Parameter, wenn dein Gerät auch ohne aktive Ansteuerung in seinem Normalbetrieb weiterläuft.
Der typische Anwendungsfall ist eine Wärmepumpe. Vorkonfigurierte Wärmepumpentypen und passende Templates setzen den Parameter bereits.

**Beispiel**:

```yaml
features:
  - continuous
```

---

### `switchdevice`

Markiert ein Gerät, das nur ein- und ausgeschaltet werden kann und keine stufenlose Stromregelung unterstützt (z. B. schaltende Wärmepumpen, schaltbare Steckdosen).
In der Oberfläche werden dadurch die Einstellungen für minimalen und maximalen Strom und die Option **Dauerhaft laden** am Ladepunkt ausgeblendet.

Bei passenden Templates und vorkonfigurierten Typen ist dieser Parameter bereits gesetzt.
Setze diesen Parameter bei benutzerdefinierten Wallboxen (`type: custom`), die den Strom nicht stufenlos regeln können.

**Beispiel**:

```yaml
features:
  - switchdevice
```
