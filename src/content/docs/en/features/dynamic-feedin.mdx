These features are relevant if you have a [dynamic grid export tariff](/en/tariffs) (e.g., direct marketing, Netherlands, Australia, etc.).

## Feed-in priority

By default, evcc uses solar surplus first to charge the car.
Only then is the solar energy exported to the grid.
During times of high grid export prices, it can be beneficial to prioritise grid export and charge the car later.

<Screenshot
  name="features/screenshots/feedin-priority-modal"
  caption="Screenshot of the Feed-in priority feature with a set price limit"
/>

With the _Feed-in priority_ feature, you can set a price threshold per charging point.
When the grid export tariffs are high (shown as orange bars), charging is paused (**Smart** mode) or reduced to a minimum (**Always charge**).
