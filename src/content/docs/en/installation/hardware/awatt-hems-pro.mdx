The HEMS PRO from Awatt Electronic is a ready-to-use device for the meter cabinet that runs evcc.
It is powered directly from 230 V and has inputs for the VDE FNN contacts of the grid operator's control box, so an [external limit](/en/external-limit) needs no further hardware.
