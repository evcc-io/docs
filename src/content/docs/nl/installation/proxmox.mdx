Proxmox is een virtualisatieplatform waarmee evcc heel eenvoudig te hosten is.
Wilt u evcc op een Linux-thuisserver draaien, dan kan Proxmox een flexibel alternatief zijn, waarmee u naast evcc ook andere systemen kunt installeren.
Een evcc-installatie op [Proxmox](https://www.proxmox.com/en/) gedraagt zich dan precies hetzelfde als een installatie op een aparte Linux-server.

De volgende installatie is getest met Ubuntu 24.4.

## Handmatige installatie

1. Download een actuele Ubuntu-template naar uw server, als die er nog niet staat.
2. Maak een LXC-container op basis van Debian aan die met minimale systeembronnen is geconfigureerd.
   (8 GB schijfruimte en 512 MB RAM zijn ruim voldoende)

   Zie screenshot:

   <img src={proxmoxResources.src} alt="Screenshot van de systeembronnen" />

3. Installeer evcc zoals beschreven in de handleiding [Installatie op Debian en Ubuntu](/nl/installation/linux).
4. Update evcc via het Debian-pakketbeheer.

## Helperscript gebruiken

Gebruikt u liever een script voor de installatie, kopieer dan het bash-script via de volgende link
[Proxmox VE Helper-Scripts](https://community-scripts.github.io/ProxmoxVE/scripts?id=evcc) in de Proxmox-console.

Het script maakt een container met 1 GB RAM aan. evcc is daarin al geïnstalleerd, dus u kunt direct beginnen
met de configuratiewizard. Op deze pagina staan ook andere nuttige scripts, bijv. voor back-ups naar externe systemen.
