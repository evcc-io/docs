Eind april vond na een lange coronapauze de [19e Linux Infotag](https://www.luga.de/static/LIT-2023/) plaats. De Infotag is een evenement van de opensourcecommunity dat wordt georganiseerd door de [Linux User Group Augsburg e.V. (LUGA)](https://www.luga.de/).

Naast veel andere boeiende onderwerpen was er dit jaar ook ruimte om ons project te presenteren. Inmiddels is ook de video-opname beschikbaar.
