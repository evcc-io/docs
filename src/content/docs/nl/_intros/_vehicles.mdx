Om het laden tot een gewenst laadniveau (SoC) te beperken, communiceert evcc via de API van de fabrikant rechtstreeks met het voertuig.
Resterende actieradius, capaciteit en laadstatus komen via dezelfde verbinding binnen.
De kwaliteit en beschikbaarheid van deze API’s verschillen sterk per fabrikant.
