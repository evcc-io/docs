:::caution[Experimenteel]
De MCP-server is experimenteel en kan op elk moment veranderen.
:::

Met het [Model Context Protocol](https://nl.wikipedia.org/wiki/Model_Context_Protocol) (kortweg MCP) kunt u LLM’s zoals Claude, Gemini en ChatGPT gestructureerde toegang geven tot externe systemen, zoals evcc.

De MCP-server wordt bij het opstarten ingeschakeld als experimentele functies zijn geactiveerd.

## Gebruik met Claude Code

Dit voorbeeld laat zien hoe u evcc via de CLI met Claude Code kunt gebruiken.
MCP-servers via HTTP zijn momenteel alleen beschikbaar in de [betaalde versie](https://www.anthropic.com/pricing).
Uiteraard kunt u ook andere LLM’s zoals Gemini of ChatGPT gebruiken.

1. Installeer Claude Code volgens de [officiële handleiding](https://docs.anthropic.com/en/docs/claude-code/overview).

2. Maak een lege map aan voor uw test en ga naar deze map:

   ```bash
   mkdir evcc-mcp-test
   cd evcc-mcp-test
   ```

3. Voeg evcc als MCP-server toe aan uw werkruimte:

   ```bash
   claude mcp add --transport http evcc http://localhost:7070/mcp
   ```

4. Controleer of uw evcc-installatie met de MCP-server draait door onder **Configuratie** naar de MCP-kaart te kijken.

5. Start Claude Code en voer een vraag in.

   ```bash
   claude

   ╭──────────────────────────────────────────────────────────────────────────────────────────╮
   │ > Kan ik mijn auto vandaag met zonne-energie laden?                                      │
   ╰──────────────────────────────────────────────────────────────────────────────────────────╯
   ```

6. Standaard wordt u om toestemming gevraagd voordat het systeem een verzoek naar evcc stuurt. U moet deze verzoeken bevestigen.

Nu ziet u Claude Code aan het werk en krijgt u als het goed is uiteindelijk een goed antwoord op uw vraag.
De bovenstaande vraag werkt echter alleen als u een [voorspelling van zonne-energie](/nl/tariffs#solar) hebt geconfigureerd.

## Demoserver

MCP is ingeschakeld op de demoserver op [demo.evcc.io](https://demo.evcc.io).
U kunt er dus ook direct mee testen:

```bash
claude mcp add --transport http evcc-demo https://demo.evcc.io/mcp
```

Omdat deze installatie door veel mensen wordt gebruikt, kunnen de resultaten onbetrouwbaar zijn.
