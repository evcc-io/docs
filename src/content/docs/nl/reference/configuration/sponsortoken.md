`sponsortoken` definieert een token dat op [https://sponsor.evcc.io](https://sponsor.evcc.io) wordt verstrekt.

:::tip
We raden aan het sponsortoken in de webinterface onder **Configuratie** in te voeren.
:::

**Voorbeeld**:

```yaml
sponsortoken: eyJhbGci[...]RX5s # your token from sponsor.evcc.io
```
