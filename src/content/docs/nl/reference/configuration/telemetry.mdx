De optie `telemetry` schakelt het regelmatig verzenden van laadgegevens (vermogen, energie, aandeel zonne-energie) naar evcc.io in. Er worden geen persoonsgegevens of configuratiedetails verzonden. Meer hierover leest u in het [privacybeleid](https://sponsor.evcc.io/privacy).

De geaggregeerde gegevens worden weergegeven op platforms zoals [evcc.io](https://evcc.io). De ruwe gegevens zijn beschikbaar via [https://api.evcc.io/v1/total](https://api.evcc.io/v1/total).

**Voorbeeld**:

```yaml
telemetry: true # default: false
```
