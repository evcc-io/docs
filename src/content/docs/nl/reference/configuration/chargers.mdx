Om het laden te kunnen aansturen, moet evcc met een lader kunnen communiceren.

Een lader moet minimaal de volgende configuratie hebben:

```yaml
chargers:
  - name: charger1 # referentienaam
    type: ...
    ...
```

Hieronder worden de mogelijke parameters toegelicht.

---

## Verplichte parameters

### `name`

Een korte aanduiding van de hier gedefinieerde lader. De waarde wordt gebruikt om naar de lader te verwijzen in de configuratie van het [laadpunt](/nl/reference/configuration/loadpoints#charger).

**Voorbeeld**:

```yaml
name: charger1
```

---

### `type`

Dit is het evcc-specifieke ladertype waarmee met de lader wordt gecommuniceerd. Bekende laders kunnen met het type `template` worden geïntegreerd. Het passende (template-)type vindt u onder [Apparaten - Laders](/nl/chargers).

Voor onbekende laders (of om andere redenen) stelt u een [door de gebruiker gedefinieerde lader](/nl/user-defined-devices#charger).

**Voorbeeld**:

```yaml
type: custom
```

---

## Optionele parameters

### `integrateddevice`

Deze parameter zorgt ervoor dat bij laders die zonder “voertuig” werken (bijv. warmtepomp, e-bike) geen voertuig wordt weergegeven en er ook geen voertuigherkenning plaatsvindt.

In combinatie met deze parameter kan ook een pictogram worden toegewezen (zie [`vehicle.icon`](/nl/reference/configuration/vehicles#icon)), dat dan bij de lader wordt weergegeven.

**Voorbeeld**:

```yaml
features:
  - integrateddevice
icon: bike
```

---

### `heating`

Deze parameter zorgt ervoor dat het laadniveau bij laders uit de groep “schakelbare stopcontacten (switchsockets)” in graden in plaats van in procenten wordt weergegeven.

**Voorbeeld**:

```yaml
features:
  - heating
```

---

### `continuous`

Markeert een apparaat dat in zijn eigen normale werking blijft draaien wanneer het “uitgeschakeld” is.
De gebruikersinterface toont “Normale werking” in plaats van “Stand-by”.
Een verzoek om meer vermogen (bijv. bij zonneoverschot of goedkope netstroom) heet “Boost”.

Stel deze functievlag in als uw apparaat zonder actieve aansturing in zijn normale werking blijft draaien.
Het typische voorbeeld is een warmtepomp, waarvoor voorgeconfigureerde warmtepomptypes en passende templates deze functievlag al instellen.

**Voorbeeld**:

```yaml
features:
  - continuous
```

---

### `switchdevice`

Markeert een apparaat dat alleen aan/uit kan worden geschakeld en geen traploze stroomregeling ondersteunt (bijv. aan/uit-warmtepompen, schakelbare stopcontacten).
De gebruikersinterface verbergt voor dit laadpunt de instellingen voor minimale/maximale stroom en de optie **Altijd laden**.

Passende templates en voorgeconfigureerde types stellen deze functievlag al in.
Bij een door de gebruiker gedefinieerde configuratie (`type: custom`) zonder traploze stroomregeling moet u deze functievlag zelf instellen.

**Voorbeeld**:

```yaml
features:
  - switchdevice
```
