# Style Sheet: Czech (cs)

- Address the reader formally with "vy" and "váš", lowercase, consistent with the evcc UI (vykání); never "ty", "tvůj".
- Use the imperative plural for steps the reader performs ("Otevřete **Konfigurace**") and impersonal phrasing for technical requirements ("Měřič musí poskytovat výkon").
- Headings use sentence case: only the first word and proper names are capitalised.
- Always write full diacritics (č, ř, š, ž, ů, ě); never fall back to ASCII.
- Numbers: decimal comma, non-breaking space as thousands separator (11 200 W), non-breaking space before units (11 kW) and before percent (50 %).
- Quotation marks „…“ for actual quotations, italics rather than quotes for technical terms.
- Abbreviations: např., tj., atd., tzv.
- Dates in prose: "18. února 2026" (genitive month); times 14:30.
- Single-letter prepositions and conjunctions (k, s, v, z, o, u, a, i) should ideally be followed by a non-breaking space.
- Mode names come from the UI: **Chytrý**, **Rychlé**, **Vypnuto**, **Zapnuto**, **Min+Solar**, **Solár**; "Boost" is not translated in the UI and stays **Boost**.
- Refer to a running instance as "vaše instance evcc"; "evcc" stays lowercase and is not declined.
- Decline foreign product names only where it reads naturally; keep protocol names (OCPP, MQTT, EEBUS) undeclined.
- Avoid English word order and nominal chains; prefer a verb.
- Keep the tone direct and friendly, no marketing words (pohodlně, bezproblémově).
